## 3. 为什么不是直接训练四个“完整模型”

### 3.1 当前 confidence 与 learned retrieval 是绑定的

当前 confidence head 并不是只观察最终的历史预测，它还接收 learned selector 特有的排序信息：

| Confidence 输入 | 在 learned retrieval 中的含义 | 在其他历史来源中的问题 |
|---|---|---|
| learned node-key 最高相似度 | query 与第一候选的隐空间形状相似度，越大越相似 | weekly mean 没有候选排序分数 |
| 第一、第二候选分数间隔 | selector 对第一名相对第二名的确定程度 | weekly mean 没有第一名、第二名 |
| learned 权重集中度 | softmax 是否集中到少数候选 | weekly mean 使用全部合法历史的均值 |
| future disagreement | 候选 future 之间的方差 | 三种模式都有，但候选集合不同 |
| level match | query 与候选统计水平的匹配程度 | raw L1 与 learned 的候选集合不同 |
| memory-base disagreement | 历史预测与当前窗口预测的差距 | 三种模式都有，语义一致 |

learned node-key 使用 cosine similarity。设 query 节点 key 为 $z^q_{b,n}\in\mathbb R^{D_r}$，候选 key 为 $z^k_{b,n}\in\mathbb R^{D_r}$，二者经过 L2 归一化，则：

\[
s^{\mathrm{learn}}_{b,n,k}
=
\left(z^q_{b,n}\right)^\top z^k_{b,n},
\qquad
s^{\mathrm{learn}}_{b,n,k}\in[-1,1].
\]

其中 $b$ 是 query，$n$ 是节点，$k$ 是历史候选，$D_r=32$ 是 retrieval key 维度。分数越大表示 learned encoder 认为二者越相似。

raw L1 使用的是标准化原始窗口距离：

\[
d^{\mathrm{raw}}_{b,n,k}
=
\frac{1}{|\Omega^X_{b,n,k}|}
\sum_{(t,c)\in\Omega^X_{b,n,k}}
\left|
\widetilde X^q_{b,t,n,c}
-
\widetilde X^k_{b,t,n,c}
\right|,
\qquad
d^{\mathrm{raw}}_{b,n,k}\ge 0.
\]

$\widetilde X^q$ 和 $\widetilde X^k$ 分别是 query 与历史候选的标准化 context，形状均为 $T\times N\times C$；$\Omega^X_{b,n,k}$ 是二者在节点 $n$ 上共同有观测的位置。raw L1 越小越相似，而 learned cosine 越大越相似，二者的数值范围、方向和训练语义都不同。

如果把 raw L1 距离直接放进原 confidence 特征位置，那么模型结果的变化可能来自两件事：

1. 历史候选来源变了；
2. confidence 输入的数值范围和语义也变了。

这时即使最终 MAE 改变，也不能判断究竟是 selector 更好，还是 confidence 更容易利用某一种分数。把 weekly mean 缺少的 learned 分数强行填成 0 同样不公平，因为 0 会被网络解释为一个真实的输入值，而不是“该特征不存在”。

### 3.2 两层实验如何消除混杂变量

第一层只比较历史来源。所有含历史的方法都关闭 confidence，统一使用第 5.1 节的 horizon-only fusion。该 fusion 只接收：

- $\widehat Y^{\mathrm{base}}\in\mathbb R^{B\times H\times N\times C}$；
- $\widehat Y^{\mathrm{mem}}\in\mathbb R^{B\times H\times N\times C}$；
- memory 有效掩码 $M\in\{0,1\}^{B\times H\times N\times C}$；
- 12 个与样本和节点无关的 horizon 权重 $\alpha\in(0,1)^H$。

因此 weekly mean、raw L1 top-K 和 learned top-K 的 fusion 输入接口完全相同，唯一变化是 $\widehat Y^{\mathrm{mem}}$ 的来源。A 至 D 的差异可以归因于历史来源及其聚合方式。

第二层固定第一层胜出的历史来源，只切换 confidence：

| 对照 | 固定不变 | 唯一变化 | 回答的问题 |
|---|---|---|---|
| A/B/C/D 来源对照 | backbone、数据、horizon fusion、训练设置 | 历史来源 | 哪种历史信息更有用？ |
| D 对 E confidence 对照 | learned 候选、learned 权重、backbone、数据 | 是否使用 confidence head | confidence 是否带来额外收益？ |

例如，若 raw L1 + horizon 的 MAE 为 3.15，learned + horizon 的 MAE 为 3.12，则 learned 历史来源相对 raw 更好。随后 learned + confidence 的 MAE 若为 3.10，才能把 3.12 到 3.10 的改善归因于 confidence。若一开始就让 raw 和 learned 使用不同语义的 confidence 特征，这两个结论会混在一起。

最终融合相对 base 的 MAE 增益定义为：

\[
G_{\mathrm{final}}
=
\frac{
\operatorname{MAE}_{\mathrm{base}}
-
\operatorname{MAE}_{\mathrm{final}}
}{
\operatorname{MAE}_{\mathrm{base}}
}
\times100\%.
\]

$G_{\mathrm{final}}>0$ 表示融合后优于只使用当前窗口的 backbone。

### 4.3 Confidence 指标

对 validation 样本 $b$、预测步 $h$、节点 $n$，定义：

\[
e^{\mathrm{base}}_{b,h,n}
=
\frac{1}{C}
\sum_{c=1}^{C}
\left|
\widehat Y^{\mathrm{base}}_{b,h,n,c}
-Y_{b,h,n,c}
\right|,
\]

\[
e^{\mathrm{mem}}_{b,h,n}
=
\frac{1}{C}
\sum_{c=1}^{C}
\left|
\widehat Y^{\mathrm{mem}}_{b,h,n,c}
-Y_{b,h,n,c}
\right|.
\]

历史信息有帮助的二元标签为：

\[
u_{b,h,n}
=
\mathbb I
\left(
e^{\mathrm{mem}}_{b,h,n}
<
e^{\mathrm{base}}_{b,h,n}
\right),
\qquad
u\in\{0,1\}^{B\times H\times N}.
\]

其中 $u=1$ 表示 memory 在该位置比 base 更准确。定义有效评价集合：

这里的 $u$ 是训练完成后的评价标签，需要使用 validation 的真实 future，因此只能用于离线诊断，不能作为推理输入。当前模型训练 confidence 时使用的是平滑软标签：

\[
u^{\mathrm{soft}}_{b,h,n}
=
\sigma\left(
\frac{
e^{\mathrm{base}}_{b,h,n}
-e^{\mathrm{mem}}_{b,h,n}
-m
}{\tau_{\mathrm{help}}}
\right),
\qquad
u^{\mathrm{soft}}\in(0,1)^{B\times H\times N}.
\]

其中 $m$ 是要求 memory 至少优于 base 多少的 margin，当前 $m=0$；$\tau_{\mathrm{help}}=0.1$ 是把误差差值转换为平滑概率的温度。训练时真实 future 只负责提供监督目标；推理时 confidence 只能根据 query、检索结果和 base-memory 差异计算，不能访问真实 future。下面的 AUROC、AUPRC 和 Brier 使用硬标签 $u$，用于检查训练得到的 confidence 是否具有清晰的“memory 是否真的更好”语义。

\[
\Omega_{\mathrm{mem}}
=
\left\{
(b,h,n)
\mid
Y_{b,h,n}\text{ 有观测且 memory 有效}
\right\},
\qquad
M=|\Omega_{\mathrm{mem}}|.
\]

$M$ 是有效节点-预测步位置总数。为简化后续公式，用 $i\in\{1,\ldots,M\}$ 表示 $\Omega_{\mathrm{mem}}$ 中的一个位置，并记：

- $u_i\in\{0,1\}$：memory 是否比 base 准确；
- $q_i\in[0,1]$：confidence head 输出的历史有用概率；
- $e_i^{\mathrm{base}}$、$e_i^{\mathrm{mem}}$：base 和 memory 的物理速度绝对误差。

下面六类指标分别检查排序能力、概率校准、分布是否坍缩以及高置信度是否对应真实收益，不能相互替代。

#### 4.3.1 AUROC：正负位置的排序能力

定义正样本集合与负样本集合：

\[
\Omega^+=\{i\mid u_i=1\},
\qquad
\Omega^-=\{i\mid u_i=0\},
\]

其样本数分别为 $M^+=|\Omega^+|$ 和 $M^-=|\Omega^-|$。AUROC 可以写成正负样本两两比较的概率：

\[
\operatorname{AUROC}
=
\frac{1}{M^+M^-}
\sum_{i\in\Omega^+}
\sum_{j\in\Omega^-}
\left[
\mathbb I(q_i>q_j)
+\frac{1}{2}\mathbb I(q_i=q_j)
\right].
\]

它表示：随机抽取一个“memory 有帮助”的位置和一个“memory 无帮助”的位置，模型给前者更高 confidence 的概率。

- AUROC = 1：排序完全正确；
- AUROC = 0.5：与随机排序相当；
- AUROC < 0.5：confidence 的方向可能学反了。

AUROC 不要求先指定 confidence 阈值，但它只衡量排序，不保证 $q_i=0.8$ 真的对应约 80% 的成功概率。
只有 validation 中同时存在正样本和负样本，即 $M^+>0$ 且 $M^->0$ 时 AUROC 才有定义；否则应报告 `undefined`，不能用 0 代替。

#### 4.3.2 AUPRC：正样本识别质量

给定 confidence 阈值 $\tau\in[0,1]$，把 $q_i\ge\tau$ 的位置预测为“memory 有帮助”。定义：

\[
\operatorname{TP}(\tau)
=
\sum_{i=1}^{M}
\mathbb I(u_i=1, q_i\ge\tau),
\]

\[
\operatorname{FP}(\tau)
=
\sum_{i=1}^{M}
\mathbb I(u_i=0, q_i\ge\tau),
\]

\[
\operatorname{FN}(\tau)
=
\sum_{i=1}^{M}
\mathbb I(u_i=1, q_i<\tau).
\]

其中 TP 是正确识别的有帮助位置，FP 是被误判为有帮助的位置，FN 是漏掉的有帮助位置。精确率与召回率为：

\[
\operatorname{Precision}(\tau)
=
\frac{\operatorname{TP}(\tau)}
{\operatorname{TP}(\tau)+\operatorname{FP}(\tau)},
\]

\[
\operatorname{Recall}(\tau)
=
\frac{\operatorname{TP}(\tau)}
{\operatorname{TP}(\tau)+\operatorname{FN}(\tau)}.
\]

AUPRC 是 Precision-Recall 曲线下的面积：

\[
\operatorname{AUPRC}
=
\int_{0}^{1}
\operatorname{Precision}(r)\,\mathrm dr,
\]

其中 $r$ 表示 recall。AUPRC 越大越好。正样本比例为：

\[
\pi
=
\frac{M^+}{M}
=
\frac{1}{M}\sum_{i=1}^{M}u_i.
\]

常数或随机排序的 AUPRC 基线约为 $\pi$。当 memory 只在少部分位置有效时，AUPRC 比 AUROC 更能反映模型能否准确找到这些少数有用位置。
若 $M^+=0$，则不存在可召回的正样本，AUPRC 同样应报告 `undefined`。

#### 4.3.3 Brier score：置信概率是否可信

\[
\operatorname{Brier}
=
\frac{1}{M}
\sum_{i=1}^{M}
\left(q_i-u_i\right)^2.
\]

Brier 同时惩罚错误方向和过度自信，越小越好：

- Brier = 0：每个概率都完全正确；
- 若始终预测正样本比例 $q_i=\pi$，常数基线为 $\pi(1-\pi)$；
- 模型 Brier 必须低于该常数基线，才能说明输出概率比“永远猜平均比例”更有信息。

例如，真实标签 $u_i=1$ 时，预测 $q_i=0.9$ 的平方误差是 0.01，而预测 $q_i=0.1$ 的平方误差是 0.81。

#### 4.3.4 Confidence 分位数：检查输出是否坍缩

confidence 均值为：

\[
\bar q
=
\frac{1}{M}
\sum_{i=1}^{M}q_i.
\]

第 $p$ 分位数定义为：

\[
Q_p(q)
=
\inf\left\{
x\mid
\frac{1}{M}
\sum_{i=1}^{M}
\mathbb I(q_i\le x)
\ge p
\right\}.
\]

报告 $Q_{0.1}$、$Q_{0.5}$、$Q_{0.9}$，分别记为 q10、中位数和 q90：

- q10：约 10% 的 confidence 不超过该值；
- 中位数：一半样本低于、一半样本高于该值；
- q90：约 90% 的 confidence 不超过该值。

若 q10、median、q90 都接近 0.5，说明 confidence 几乎没有区分不同位置；若 q10 与 q90 有明显间隔，只说明输出有变化，是否变化正确仍要由 AUROC、AUPRC 和分组 gain 判断。

#### 4.3.5 Fusion weight 分位数：历史信息实际注入了多少

confidence $q_{b,h,n}$ 不是最终融合比例。当前模型先用 horizon 参数限制最大注入量：

\[
g_{b,h,n}
=
M_{b,h,n}\,\sigma(a_h)\,q_{b,h,n},
\qquad
g\in[0,1]^{B\times H\times N}.
\]

其中：

- $M_{b,h,n}\in\{0,1\}$：memory 是否有效；
- $a_h$：第 $h$ 个 horizon 的可训练融合 logit；
- $\sigma(a_h)$：第 $h$ 个 horizon 的最大历史注入比例；
- $q_{b,h,n}$：confidence；
- $g_{b,h,n}$：最终实际 fusion weight。

最终预测为：

\[
\widehat Y^{\mathrm{final}}_{b,h,n,c}
=
\widehat Y^{\mathrm{base}}_{b,h,n,c}
+g_{b,h,n}
\left(
\widehat Y^{\mathrm{mem}}_{b,h,n,c}
-
\widehat Y^{\mathrm{base}}_{b,h,n,c}
\right).
\]

对所有有效位置的 $g$ 计算均值、q10、中位数和 q90。若 confidence 分布较宽但 fusion weight 全部接近 0，说明 horizon gate 实际关闭了历史分支；若 fusion weight 较大但 final 比 base 更差，说明模型注入了有害历史。

#### 4.3.6 Confidence 四分位分组 Memory Gain：高置信度是否真的更有用

按照 confidence 从低到高把 $\Omega_{\mathrm{mem}}$ 等分为四组：

\[
\mathcal Q_1,
\mathcal Q_2,
\mathcal Q_3,
\mathcal Q_4,
\]

分别对应最低 25%、25% 至 50%、50% 至 75% 和最高 25% confidence。第 $r$ 组的绝对 memory gain 为：

\[
\Delta_r^{\mathrm{mem}}
=
\frac{1}{|\mathcal Q_r|}
\sum_{i\in\mathcal Q_r}
\left(
e_i^{\mathrm{base}}
-
e_i^{\mathrm{mem}}
\right).
\]

$\Delta_r^{\mathrm{mem}}$ 的单位与速度相同：

- $\Delta_r^{\mathrm{mem}}>0$：该组 memory 比 base 更准；
- $\Delta_r^{\mathrm{mem}}<0$：该组 memory 反而引入噪声。

也报告相对 gain：

\[
G_r^{\mathrm{mem}}
=
\frac{
\operatorname{MAE}^{\mathrm{base}}_r
-
\operatorname{MAE}^{\mathrm{mem}}_r
}{
\operatorname{MAE}^{\mathrm{base}}_r
}
\times100\%.
\]

若 confidence 具有正确语义，应观察到从 $\mathcal Q_1$ 到 $\mathcal Q_4$ 的 memory gain 总体上升，并且最高 confidence 组具有明确正收益。若四组 gain 没有上升趋势，或者最高 confidence 组仍为负，则 confidence 即使 AUROC 略高于 0.5，也没有形成可靠的融合依据。

### 4.4 六类指标分别回答什么

| 指标 | 核心问题 | 好结果 |
|---|---|---|
| AUROC | 有帮助位置是否排在无帮助位置前面？ | 明显高于 0.5 |
| AUPRC | 能否准确找到少数真正有帮助的位置？ | 明显高于正样本比例 $\pi$ |
| Brier | confidence 数值能否作为可信概率？ | 低于常数基线 $\pi(1-\pi)$ |
| Confidence 分位数 | 输出是否全部挤在同一个值附近？ | q10 与 q90 有合理间隔 |
| Fusion weight 分位数 | 历史分支实际上注入了多少？ | 非零且不过度集中，同时 final 有收益 |
| 分组 memory gain | confidence 越高，历史是否真的越有帮助？ | gain 随四分位总体上升，Q4 为正 |

只有排序、校准、分布和实际 gain 同时合理，才能认为 confidence 学到了可用于融合的“历史可靠性”。

| 结果 | 解释 | 后续动作 |
|---|---|---|
| memory 优于 base，final 进一步提高 | 历史与融合均有效 | 进入四模式来源对照 |
| memory 优于 base，final 未提高 | confidence/fusion 抵消收益 | 仍做来源对照，随后重点删除 confidence |
| memory 不如 base，final 接近 base | fallback 有效，但 learned history 不稳定 | 通过四模式判断简单历史是否更好 |
| final 明显差于 base | 当前融合有害 | 四模式只使用 horizon-only fusion |

## 5. 阶段 1：四模式历史来源对照

### 5.1 统一融合公式

四模式来源实验不使用 confidence。对存在 memory 的方法，使用相同的 horizon-only fusion：

\[
\alpha_h=\sigma(a_h),
\qquad
\alpha\in(0,1)^H,
\]

\[
\widehat Y^{\mathrm{final}}_{b,h,n,c}
=
\widehat Y^{\mathrm{base}}_{b,h,n,c}
+M_{b,h,n,c}\alpha_h
\left(
\widehat Y^{\mathrm{mem}}_{b,h,n,c}
-
\widehat Y^{\mathrm{base}}_{b,h,n,c}
\right).
\]

其中：

- $a_h$：第 $h$ 个 horizon 的可训练标量；
- $\alpha_h$：该 horizon 允许使用历史信息的最大比例；
- $M_{b,h,n,c}\in\{0,1\}$：memory 是否有效；
- $\alpha$ 只有 $H=12$ 个可训练参数；
- 当 $M=0$ 时，最终结果严格回退为 base。

### 5.2 四种模式

| 编号 | `downstream_mode` | 历史候选 | 聚合 | 可训练模块 |
|---|---|---|---|---|
| A | `base_only` | 无 | 无 | backbone |
| B | `weekly_mean_horizon` | 全部合法同 weekday-slot 历史 | 缺失掩码下均匀平均 | backbone + 12 个 horizon 参数 |
| C | `raw_l1_topk_horizon` | 原始 context L1 距离最小的 $K=5$ 个历史事件 | 缺失掩码下均匀平均 | backbone + 12 个 horizon 参数 |
| D | `learned_topk_horizon` | learned node key 得分最高的 $K=5$ 个历史事件 | learned softmax 权重 | backbone + 12 个 horizon 参数 |

当前已训练模型记为：

| 编号 | `downstream_mode` | 说明 |
|---|---|---|
| E | `learned_topk_confidence` | 当前 learned top-K + confidence + horizon fusion，已有 epoch 37 checkpoint |

E 不需要重新训练。A 至 D 使用相同 seed=42、相同 calibration 数据、相同 early stopping 和相同 backbone 初始化规则重新训练。

### 5.3 Weekly mean 与 raw L1 的候选边界

所有历史模式必须同时满足：

1. 候选 context-end 与 query context-end 具有相同 weekday-slot；
2. 候选 `future_end` 严格早于 query `context_start`；
3. 不使用 validation 或 test 数据构建候选；
4. 缺失 future 只在有效观测上参与聚合；
5. 不执行水平对齐或最后值平移。

weekly mean 使用全部合法候选，候选轴为：

\[
F^{\mathrm{week}}
\in
\mathbb R^{B\times H\times N\times R\times C},
\qquad R\le 32.
\]

raw L1 与 learned top-K 使用：

\[
F^{\mathrm{topK}}
\in
\mathbb R^{B\times H\times N\times K\times C},
\qquad K=5.
\]

raw L1 距离在训练集 scaler 标准化后的 context 上计算，并且只统计 query 与候选共同有观测的位置；不得使用 future 参与 raw L1 排序。

### 5.4 公平性约束

- A 至 D 使用相同的 6846 个 calibration 窗口；
- batch size、learning rate、weight decay、epochs、patience 完全一致；
- 不修改预训练 checkpoint 和 Bank；
- 不修改 backbone hidden dimension；
- 不为任一模式单独调参；
- 只用 validation 选 checkpoint；
- 本阶段禁止运行 test；
- 日志必须保存模式、参数量、候选覆盖率和每轮 validation 指标。

## 6. 阶段 1 去留标准

所有判断首先基于 overall validation MAE，同时检查 15/30/60 分钟结果是否一致。

| 对照结果 | 决策 |
|---|---|
| B、C、D 均不优于 A | 当前历史分支无下游价值，停止扩展历史模块 |
| B 最优，C/D 没有稳定优势 | 保留 weekly mean，删除 learned selector |
| C 与 D 差距不超过 0.2% | 采用更简单的 raw L1 top-K，删除 learned selector 与相应预训练目标 |
| D 比 C 至少改善 0.5%，且比 A 至少改善 0.5% | learned retrieval 通过单 seed 筛选，保留进入多 seed |
| D 比 C 改善处于 0.2% 至 0.5% | 只对 C、D 做多 seed，不运行其他扩展 |

相对改善定义为：

\[
\operatorname{Gain}(P,Q)
=
\frac{
\operatorname{MAE}_{Q}
-
\operatorname{MAE}_{P}
}{
\operatorname{MAE}_{Q}
}
\times100\%,
\]

其中 $P$ 是待验证方法，$Q$ 是对照方法。单 seed 的 0.5% 只作为筛选门槛，不作为论文统计显著性结论。

## 7. 阶段 2：Confidence 独立消融

阶段 2 不是必跑。只有阶段 1 证明某种历史来源优于 base 时才进入。

若 D 是胜出模式，直接比较：

| 模式 | 历史来源 | Fusion |
|---|---|---|
| D | learned weighted top-K | horizon-only |
| E | learned weighted top-K | confidence × horizon weight |

判断：

- E 比 D 的 validation MAE 改善至少 0.5%，且 confidence AUROC、Brier 优于常数基线：保留 confidence；
- E 与 D 差距小于 0.2%：删除 confidence head，保留更简单的 horizon-only fusion；
- E 比 D 更差：删除 confidence head，并记录为负结果；
- confidence 指标好但最终 MAE 无改善：confidence 有识别能力，但当前融合没有转化为预测收益，第一版不继续重构。

若 B 或 C 胜出，不为它们重新设计新的 confidence 特征；第一版直接保留 horizon-only fusion，避免打开新的模型设计分支。

## 8. 阶段 3：多随机种子与最终 test

只有阶段 1/2 选出唯一保留模式后才运行多 seed。

第一轮只固定同一个预训练 checkpoint，运行下游 seed：

```text
42, 2024, 2025
```

报告 validation MAE、RMSE、MAPE 的均值与标准差。若保留 learned retrieval，需要在论文最终实验阶段补充多预训练 seed；这不属于当前筛选阶段。

模式、超参数和去留结论冻结后，才允许统一执行 test。论文 ST-SSDL 的 Step 12 指标只能与本模型 test 的 60 分钟指标比较，不能与 overall validation MAPE 比较。
