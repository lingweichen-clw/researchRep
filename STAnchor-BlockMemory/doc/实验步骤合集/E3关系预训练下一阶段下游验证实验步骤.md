## 3. 模型模式、预测分支与指标定义

本节给出后续命令和结果表中全部关键术语的定义。读者不需要查阅其他文档。

### 3.1 基本符号与张量维度

本实验使用 METR-LA，主要符号如下：

| 符号 | 当前取值 | 含义 |
|---|---:|---|
| $B$ | 由 batch size 决定 | 一个训练或评估批次中的样本数 |
| $T_f$ | 12 | 下游 backbone 使用的最近历史步数，即最近 60 分钟 |
| $T_r$ | 288 | 检索编码器使用的历史步数，即最近 24 小时 |
| $H$ | 12 | 需要预测的未来步数，即未来 60 分钟 |
| $N$ | 207 | 交通传感器节点数 |
| $C$ | 1 | 速度特征通道数 |
| $K$ | 5 | 每个 query 节点保留的历史候选数 |

真实未来值和三种预测均采用相同形状：

\[
\mathbf{Y},\ \widehat{\mathbf{Y}}^{\mathrm{base}},\
\widehat{\mathbf{Y}}^{\mathrm{mem}},\
\widehat{\mathbf{Y}}^{\mathrm{final}}
\in \mathbb{R}^{B\times H\times N\times C}.
\]

其中，$b\in\{1,\ldots,B\}$ 表示样本，$h\in\{1,\ldots,H\}$ 表示未来预测步，$n\in\{1,\ldots,N\}$ 表示节点，$c\in\{1,\ldots,C\}$ 表示特征通道。

观测掩码定义为：

\[
O_{b,h,n,c}\in\{0,1\},
\]

其中 $O_{b,h,n,c}=1$ 表示该真实未来速度有效，$O_{b,h,n,c}=0$ 表示该位置缺失，计算误差时必须排除。

### 3.2 Base prediction：不使用历史检索的基础预测

基础预测只使用当前样本最近 12 步速度：

\[
\mathbf{X}^{\mathrm{recent}}
\in\mathbb{R}^{B\times T_f\times N\times C},
\qquad T_f=12.
\]

轻量下游 backbone 对每个节点共享同一个 MLP，输出：

\[
\widehat{\mathbf{Y}}^{\mathrm{base}}
=f_{\mathrm{base}}\!\left(\mathbf{X}^{\mathrm{recent}}\right)
\in\mathbb{R}^{B\times H\times N\times C}.
\]

它回答的问题是：**完全不读取历史 Memory Bank，只依赖最近 60 分钟，模型能预测到什么程度？** 因而它是判断历史检索是否真正有用的基线分支。

### 3.3 Memory prediction：检索历史 future 的加权预测

检索编码器读取最近一天的上下文：

\[
\mathbf{X}^{\mathrm{retrieval}}
\in\mathbb{R}^{B\times T_r\times N\times C},
\qquad T_r=288,
\]

并为每个 query 节点检索 $K=5$ 个历史事件。第 $k$ 个历史事件在同一节点上的真实后续序列记为：

\[
F_{b,h,n,k,c}
\in\mathbb{R},
\qquad
\mathbf{F}\in\mathbb{R}^{B\times H\times N\times K\times C}.
\]

这里的 $F_{b,h,n,k,c}$ 来自 Memory Bank 中已经发生过的历史事件，不是当前 query 的真实未来。检索器还为每个节点候选产生归一化权重：

\[
w_{b,n,k}\ge 0,
\qquad
\sum_{k\in\mathcal{V}_{b,h,n,c}}w_{b,n,k}>0,
\]

其中 $\mathcal{V}_{b,h,n,c}$ 是在该预测位置具有有效历史 future 的候选集合。实际聚合会针对缺失值重新归一化：

\[
\widehat{Y}^{\mathrm{mem}}_{b,h,n,c}
=
\frac{
\displaystyle\sum_{k=1}^{K}
w_{b,n,k}M^{F}_{b,h,n,k,c}F_{b,h,n,k,c}
}{
\displaystyle\sum_{k=1}^{K}
w_{b,n,k}M^{F}_{b,h,n,k,c}
},
\]

其中：

- $M^{F}_{b,h,n,k,c}\in\{0,1\}$ 是历史候选 future 的有效掩码；
- $\widehat{Y}^{\mathrm{mem}}_{b,h,n,c}$ 是只依赖历史检索结果得到的预测；
- 当分母为 0 时，该位置被记为 memory 无效，不参与 `MemoryMAE`，最终模型会退回 base prediction。

为避免未来信息泄漏，候选历史事件必须满足：**候选事件的 future 结束时间早于当前 query 上下文的起始时间**。因此当前待预测的真实未来不会被放入候选集合。

### 3.4 `horizon-only` 到底是什么意思

`learned_topk_horizon` 中的 `horizon-only` 是一种**融合模式**，不是一个误差指标，也不是“只预测某一个 horizon”。它表示：

> 每个未来预测步 $h$ 只学习一个全局融合强度；该强度在所有样本和节点之间共享，不使用样本级 confidence 网络。

对第 $h$ 个预测步，模型学习一个标量参数 $a_h$，并将其限制到 $0$ 到 $1$：

\[
\rho_h=\sigma(a_h),
\qquad
\boldsymbol{\rho}\in\mathbb{R}^{1\times H\times1\times1},
\]

其中 $\sigma(\cdot)$ 是 Sigmoid 函数，$\rho_h$ 表示第 $h$ 个未来步允许使用多少历史 memory。对于 memory 有效的位置，最终预测为：

\[
\widehat{Y}^{\mathrm{final}}_{b,h,n,c}
=(1-\rho_h)\widehat{Y}^{\mathrm{base}}_{b,h,n,c}
+\rho_h\widehat{Y}^{\mathrm{mem}}_{b,h,n,c}.
\]

如果 memory 无效，则融合权重强制为 0：

\[
\widehat{Y}^{\mathrm{final}}_{b,h,n,c}
=\widehat{Y}^{\mathrm{base}}_{b,h,n,c}.
\]

因此，`horizon-only` 具有以下边界：

- 有 $H=12$ 个可训练 horizon 融合参数；
- 同一个未来步的所有样本和节点共用同一个 $\rho_h$；
- 不训练 confidence head，日志中的 `confidence_head=0` 和 `val_confidence=0` 是正常现象；
- 它不是简单的 $0.5$ 平均，也不是 memory-only；
- 它用于先隔离检验“历史来源是否有效”，避免同时改变历史来源和 confidence 语义。

后续 `learned_topk_confidence` 模式才会额外预测节点级置信度 $g_{b,h,n}\in[0,1]$，其实际融合权重为 $\rho_hg_{b,h,n}$。本阶段暂不使用该模式。

### 3.5 MAE、RMSE 与 MAPE

所有正式评估指标都先经过 inverse transform，恢复到 METR-LA 的原始速度数值尺度，再计算误差。设有效目标位置总数为：

\[
M_O=\sum_{b=1}^{B}\sum_{h=1}^{H}\sum_{n=1}^{N}\sum_{c=1}^{C}O_{b,h,n,c}.
\]

#### MAE：平均绝对误差

\[
\operatorname{MAE}(\widehat{\mathbf{Y}},\mathbf{Y};\mathbf{O})
=\frac{1}{M_O}
\sum_{b,h,n,c}
O_{b,h,n,c}
\left|\widehat{Y}_{b,h,n,c}-Y_{b,h,n,c}\right|.
\]

MAE 越低越好，是本项目选择最佳 checkpoint 和比较模型的主指标。

#### RMSE：均方根误差

\[
\operatorname{RMSE}(\widehat{\mathbf{Y}},\mathbf{Y};\mathbf{O})
=\sqrt{
\frac{1}{M_O}
\sum_{b,h,n,c}
O_{b,h,n,c}
\left(\widehat{Y}_{b,h,n,c}-Y_{b,h,n,c}\right)^2
}.
\]

RMSE 对少量大误差更敏感。若 MAE 接近而 RMSE 明显升高，说明模型可能产生了更严重的极端预测错误。

#### MAPE：平均绝对百分比误差

实现中只统计真实值满足 $|Y_{b,h,n,c}|>10^{-5}$ 的有效位置。定义百分比有效掩码：

\[
P_{b,h,n,c}
=O_{b,h,n,c}\,\mathbb{I}\!\left(|Y_{b,h,n,c}|>10^{-5}\right),
\qquad
M_P=\sum_{b,h,n,c}P_{b,h,n,c}.
\]

则：

\[
\operatorname{MAPE}
=\frac{100}{M_P}
\sum_{b,h,n,c}
P_{b,h,n,c}
\frac{\left|\widehat{Y}_{b,h,n,c}-Y_{b,h,n,c}\right|}
{|Y_{b,h,n,c}|}.
\]

MAPE 越低越好，但它对接近 0 的真实速度较敏感，因此本项目以 MAE 为主，RMSE 和 MAPE 用作补充证据。

训练日志中的 `train_total`、`train_forecast` 和 `val_total` 是**归一化模型空间中的优化损失**；日志中的 `val_mae`、`val_rmse`、`val_mape` 是**恢复到原始速度尺度后的评估指标**。两组数值不在同一尺度上，不能直接互相比较。

在 `horizon-only` 模式下没有 confidence 损失，因此：

\[
L_{\mathrm{total}}=L_{\mathrm{forecast}},
\qquad
L_{\mathrm{confidence}}=0.
\]

### 3.6 `BaseMAE`、`MemoryMAE`、`FinalMAE` 和 gain

分支诊断不是增加新的预测任务，而是把同一次前向传播中的三条预测分别评分：

| 字段 | 计算对象 | 统计范围 | 越低/越高越好 |
|---|---|---|---|
| `BaseMAE` | $\widehat{\mathbf{Y}}^{\mathrm{base}}$ | 所有真实目标有效的位置 | 越低越好 |
| `CommonBaseMAE` | $\widehat{\mathbf{Y}}^{\mathrm{base}}$ | 真实目标有效且 memory 也有效的位置 | 越低越好 |
| `MemoryMAE` | $\widehat{\mathbf{Y}}^{\mathrm{mem}}$ | 与 `CommonBaseMAE` 完全相同的位置 | 越低越好 |
| `FinalMAE` | $\widehat{\mathbf{Y}}^{\mathrm{final}}$ | 所有真实目标有效的位置 | 越低越好 |

`MemoryMAE` 的含义是：**如果只采用检索到的历史 future 作为预测，在 memory 确实存在的位置上，平均绝对误差是多少？** 它直接衡量检索与聚合分支本身的质量，但不等于最终模型误差。

由于 `MemoryMAE` 会排除 memory 无效的位置，不能直接拿它与全样本 `BaseMAE` 比较。公平比较必须使用同一有效位置上的 `CommonBaseMAE`：

\[
\operatorname{MemoryGain}
=\operatorname{CommonBaseMAE}-\operatorname{MemoryMAE}.
\]

最终融合相对于 base 的收益定义为：

\[
\operatorname{FinalGain}
=\operatorname{BaseMAE}-\operatorname{FinalMAE}.
\]

两种 gain 的判读方式相同：

- gain $>0$：对应的 memory 或最终融合优于 base；
- gain $=0$：没有可测收益；
- gain $<0$：引入历史信息后误差反而增大。

memory 覆盖率定义为：

\[
\operatorname{MemoryCoverage}
=\frac{
\text{真实目标有效且 memory 有效的位置数}
}{
\text{真实目标有效的位置数}
}.
\]

覆盖率只表示“有多少位置可使用历史信息”，不表示这些历史信息一定有用。

跨 E2/E3 比较 `MemoryMAE` 时必须同时报告 `MemoryCoverage`。若两组覆盖率不同，较低的 `MemoryMAE` 可能只是因为某一组避开了更多困难位置；此时不能直接归因于 selector 更好，必须在两组 memory 都有效的交集位置上重新计算共同 MAE。第 7 节的输出命令已经同时打印覆盖率。

### 3.7 Overall 与 15/30/60 分钟指标

`overall MAE/RMSE/MAPE` 将 $H=12$ 个未来步的所有有效位置一起统计。单步指标则固定预测步 $h$，例如单步 MAE 为：

\[
\operatorname{MAE}_{h}
=
\frac{
\displaystyle\sum_{b,n,c}
O_{b,h,n,c}\left|\widehat{Y}_{b,h,n,c}-Y_{b,h,n,c}\right|
}{
\displaystyle\sum_{b,n,c}O_{b,h,n,c}
}.
\]

METR-LA 的采样间隔是 5 分钟，因此：

| 报告名称 | 数学预测步 | Python 数组索引 | 含义 |
|---|---:|---:|---|
| 15 分钟 | $h=3$ | 2 | 预测未来第 15 分钟 |
| 30 分钟 | $h=6$ | 5 | 预测未来第 30 分钟 |
| 60 分钟 | $h=12$ | 11 | 预测未来第 60 分钟 |

它们不是“前 15/30/60 分钟的累计平均”，而是对应时刻的单步误差。

### 3.8 检索诊断指标

本节开头表格中的三项 `future MAE` 都在 validation 上使用真实 future **只做离线评分**，不会在部署推理时访问 query 的真实未来。当前诊断代码将所有检索方法限制在共同有效位置 $\Omega_{\mathrm{common}}$ 上计算 MAE，避免某个方法通过少覆盖困难位置取得虚假优势。

#### Learned Top-1 future MAE

对每个 query 节点，按 learned key 分数选择排名第一的历史事件，直接把该事件的历史 future 作为预测：

\[
\widehat{Y}^{\mathrm{top1}}_{b,h,n,c}
=F_{b,h,n,1,c}.
\]

`learned Top-1 future MAE` 是 $\widehat{\mathbf{Y}}^{\mathrm{top1}}$ 在 $\Omega_{\mathrm{common}}$ 上的 MAE。它越低，说明 learned key 的第一名排序越准确。

#### Learned uniform Top-K future MAE

仍然使用 learned key 选出的 $K=5$ 个候选，但忽略 learned score 的大小，对有效候选等权聚合：

\[
\widehat{Y}^{\mathrm{uniform}}_{b,h,n,c}
=
\frac{
\displaystyle\sum_{k=1}^{K}
M^{F}_{b,h,n,k,c}F_{b,h,n,k,c}
}{
\displaystyle\sum_{k=1}^{K}M^{F}_{b,h,n,k,c}
}.
\]

该预测的 MAE 称为 `learned uniform Top-K future MAE`。它主要检验 **Top-K 候选集合本身是否选得好**，不把 softmax 权重的贡献混入结论。

#### Learned weighted Top-K future MAE

使用 learned key 选出的同一组 $K=5$ 候选，并使用检索分数产生的 softmax 权重 $w_{b,n,k}$ 聚合。其预测就是第 3.3 节定义的 $\widehat{\mathbf{Y}}^{\mathrm{mem}}$。该预测的离线 MAE 称为 `learned weighted Top-K future MAE`。

比较方式如下：

- weighted Top-K 优于 uniform Top-K：learned 权重在候选集合之上还有额外价值；
- 两者接近：收益主要来自选中了哪些候选，而不是候选内部的权重差异；
- weighted Top-K 更差：learned score 的相对大小可能不能代表 future 质量。

#### Oracle Top-1 与 Oracle gap

Oracle 在合法的历史事件候选池中，使用 query 的真实 future 事后选择误差最小的一个候选：

\[
k^{\star}_{b,n}
=\arg\min_{k\in\mathcal C_{b,n}}
\frac{
\displaystyle\sum_{h,c}
O_{b,h,n,c}M^F_{b,h,n,k,c}
\left|F_{b,h,n,k,c}-Y_{b,h,n,c}\right|
}{
\displaystyle\sum_{h,c}O_{b,h,n,c}M^F_{b,h,n,k,c}
}.
\]

其中 $\mathcal C_{b,n}$ 是经过日历和时间合法性过滤后的事件候选池。Oracle 使用真实未来，因此只能作为诊断上界，不能作为可部署方法。当前 `Oracle gap` 定义为：

\[
\operatorname{OracleGap}
=\operatorname{MAE}_{\mathrm{learned\ top1}}
-\operatorname{MAE}_{\mathrm{oracle\ top1}}.
\]

gap 越大，表示候选池中存在明显更好的历史事件，但 learned selector 尚未把它排到第一位；gap 越小，表示 learned Top-1 越接近候选池内上界。

#### Top-1 weight 与有效支持数

`top1 weight` 是每个节点排名第一候选的聚合权重 $w_{b,n,1}$。它越接近 1，权重越集中于第一名。

Top-K 权重的有效支持数定义为：

\[
K_{\mathrm{eff}}(b,n)
=\frac{1}{\displaystyle\sum_{k=1}^{K}w_{b,n,k}^{2}},
\qquad 1\le K_{\mathrm{eff}}\le K.
\]

- $K_{\mathrm{eff}}=1$：几乎只使用一个候选；
- $K_{\mathrm{eff}}=K$：$K$ 个候选近似等权；
- 它只反映权重分散程度，不直接证明检索结果正确。

#### 尚待实现的 Future Recall@K、Future NDCG@K 与 mirage separation AUC

这三项目前尚未由 `diagnose_retrieval.py` 输出，不能把它们写成已有实验结果。后续扩展诊断时采用以下固定语义：

- `Future Recall@K`：真实 future 最接近的 oracle Top-K 候选中，有多少被 learned Top-K 找回；
- `Future NDCG@K`：learned 排名是否把 future 更相似的候选排在更靠前的位置，并对列表前部错误施加更大惩罚；
- `mirage separation AUC`：learned key 分数能否区分“context 相似且 future 相似”的正样本与“context 相似但 future 不相似”的时空海市蜃楼负样本。

设 oracle Top-K 集合为 $\mathcal O_i^K$，learned Top-K 集合为 $\mathcal R_i^K$，其中 $i$ 表示一个 query-node，则：

\[
\operatorname{FutureRecall@K}_i
=\frac{|\mathcal O_i^K\cap\mathcal R_i^K|}{K}.
\]

Future NDCG 的候选相关性由 future 距离 $d^Y_{i,j}$ 转换：

\[
r^Y_{i,j}=\exp\!\left(-\frac{d^Y_{i,j}}{\tau_Y}\right),
\]

\[
\operatorname{DCG@K}_i
=\sum_{k=1}^{K}
\frac{r^Y_{i,\pi_i(k)}}{\log_2(k+1)},
\qquad
\operatorname{NDCG@K}_i
=\frac{\operatorname{DCG@K}_i}{\operatorname{IDCG@K}_i}.
\]

其中 $\pi_i(k)$ 是 learned 排名第 $k$ 的候选，$\operatorname{IDCG@K}_i$ 是按真实 future 相关性从高到低排列得到的理想 DCG，$\tau_Y>0$ 是固定 future 温度。Recall 和 NDCG 都越高越好。

### 3.9 Confidence 指标

本节指标只用于第 10 节的 `learned_topk_confidence` 模式。在 `horizon-only` 模式中 confidence 对 memory 有效位置恒为 1，不应计算或解读 AUROC、AUPRC 和 Brier。

设 $i$ 表示一个真实目标和 memory 都有效的节点-预测步位置。定义 base 与 memory 的绝对误差：

\[
e_i^{\mathrm{base}}
=\frac{1}{C}\sum_{c=1}^{C}
\left|\widehat{Y}^{\mathrm{base}}_{i,c}-Y_{i,c}\right|,
\qquad
e_i^{\mathrm{mem}}
=\frac{1}{C}\sum_{c=1}^{C}
\left|\widehat{Y}^{\mathrm{mem}}_{i,c}-Y_{i,c}\right|.
\]

真实 helpful-memory 标签与模型置信度分别为：

\[
u_i=\mathbb I\!\left(e_i^{\mathrm{mem}}<e_i^{\mathrm{base}}\right),
\qquad
q_i\in[0,1].
\]

$u_i=1$ 表示该位置使用 memory 比 base 更准确；$q_i$ 是 confidence head 预测“memory 有帮助”的概率。真实 future 只在训练监督和离线诊断中生成 $u_i$，推理时 confidence head 不可访问 $u_i$ 或真实 future。

#### AUROC

设正样本集合 $\Omega^+=\{i\mid u_i=1\}$，负样本集合 $\Omega^-=\{i\mid u_i=0\}$，则：

\[
\operatorname{AUROC}
=\frac{1}{|\Omega^+||\Omega^-|}
\sum_{i\in\Omega^+}\sum_{j\in\Omega^-}
\left[
\mathbb I(q_i>q_j)
+\frac{1}{2}\mathbb I(q_i=q_j)
\right].
\]

AUROC 表示随机取一个 helpful 位置和一个 harmful 位置时，模型把前者排得更高的概率。1 为理想排序，0.5 约等于随机，越高越好。

#### AUPRC 与 helpful-memory prevalence

对 confidence 阈值 $\eta$，令预测为 helpful 的集合是 $q_i\ge\eta$，据此计算 Precision 与 Recall；AUPRC 是 Precision-Recall 曲线下的面积，越高越好。helpful-memory prevalence 是正样本比例：

\[
\pi=\frac{1}{M}\sum_{i=1}^{M}u_i,
\]

其中 $M$ 是 memory 有效位置总数。随机或常数排序的 AUPRC 基线约为 $\pi$，因此不能只看 AUPRC 是否大于 0，必须与 $\pi$ 比较。

#### Brier score 与常数基线

\[
\operatorname{Brier}
=\frac{1}{M}\sum_{i=1}^{M}(q_i-u_i)^2.
\]

Brier 同时衡量预测方向和概率校准，越低越好。若所有位置都固定预测 $q_i=\pi$，常数基线为：

\[
\operatorname{Brier}_{\mathrm{constant}}=\pi(1-\pi).
\]

模型 Brier 低于该基线，才说明 confidence 比“永远预测平均 helpful 比例”包含更多信息。

#### Confidence 四分位 memory gain

按照 $q_i$ 从低到高把有效位置等分成四组 $\mathcal Q_1,\ldots,\mathcal Q_4$。第 $r$ 组的 memory gain 为：

\[
\Delta_r^{\mathrm{mem}}
=\frac{1}{|\mathcal Q_r|}
\sum_{i\in\mathcal Q_r}
\left(e_i^{\mathrm{base}}-e_i^{\mathrm{mem}}\right).
\]

若 confidence 语义成立，$\Delta_r^{\mathrm{mem}}$ 应从低置信度组到高置信度组总体上升，并且最高组 $\mathcal Q_4$ 应为正。仅有 AUROC 略高于 0.5，但分组 gain 没有上升，仍不能说明 confidence 可用于可靠融合。

## 8. seed=42 的通过与停止门槛

### 8.1 明确通过

1. E3 `MemoryMAE` 低于 E2，说明离线检索改善进入了下游 memory 分支；
2. E3 整体 `FinalMAE` 不高于 E2；

### 8.3 停止 E3 下游扩展

若 E3 `MemoryMAE` 没有改善，并且 `FinalMAE` 比 E2 高 0.01 以上，则停止：

- 不训练 E3 confidence；
- 不调整 encoder、融合器或超参数来追逐结果；
- 将 E3 定位为“改善离线 Top-K 检索但未转化为预测收益”，重新审视预训练目标与下游接口之间的对应关系。
