# E5 项目压缩与主线精炼实施计划

## 1. 目标

本轮精炼把仓库收敛到以下正式主线：

1. `Global288 + Latent48 + OffsetDecay + SymNorm` 未来关系检索；
2. 目标域历史 Bank 与 Top-5 OffsetDecay 聚合；
3. 冻结下游基础模型后的 PostHoc 风险诊断与检索修正；
4. E2、E3、E5A 只保留为论文方法演进或消融证据，不再保留可重建的大型 Bank。

本轮不改变数据划分、归一化、未来信息边界、Top-5 候选协议或当前预训练 checkpoint。

## 2. 安全边界

- 当前 `downstream_global288_posthoc_error_aware` 队列结束前，不修改会被后续 Python 子进程加载的训练代码、配置和队列脚本。
- 当前正式 Latent48 pretrained Bank 与 random Bank 不删除。
- checkpoint、完整训练日志、指标和诊断报告只有在明确记录结论后才删除。
- 旧 Bank 是由保留的 checkpoint、配置、训练数据和图重新生成的派生产物，可以删除。
- 删除前逐项解析绝对路径，并验证目标位于本仓库 `artifacts` 内。
- 不按通配符批量删除，不删除名称或用途存在歧义的目录。

## 5. PostHoc 特征修正

纯 Latent48 Bank 不包含 profile/latent 子空间分解。当前实现将缺失的 `profile_scores` 和 `latent_scores` 都回退到完整 48 维 key 相似度，导致两个诊断输入重复。

修正后的诊断特征为 9 维：

1. 预测的基础模型风险；
2. 完整 Latent48 key 的 `retrieval_similarity`；
3. Top-1 与 Top-2 检索分数间隔；
4. Top-5 有效支持度；
5. 候选 future 离散度；
6. 候选修正方向一致性；
7. level match；
8. memory 与 base 的分歧；
9. horizon 相对位置。

融合公式保持不变：

\[
w_{b,h,n}
=
\sigma\!\left(
b+\sum_{d=1}^{9}f_d(z_{b,h,n,d})
\right),
\]

\[
\widehat Y^{\mathrm{final}}
=
\widehat Y^{\mathrm{base}}
+w\left(
\widehat Y^{\mathrm{mem}}-\widehat Y^{\mathrm{base}}
\right).
\]

该修正不改变 Bank、候选集合、聚合 future 或当前 query 的未来信息边界。

## 6. 日志精炼

预训练日志按 loss mode 输出：

- relation 模式只输出 reconstruction、relation loss、anchors、relation candidates、teacher/student effective support 和 masked positions；
- hard-label 模式才输出 positive pairs 和 hard negatives；
- adapter 关闭时不输出任何 `adapter_*=0`；
- profile 已退出主线，不再输出 `val_profile=0`。

下游日志按 downstream mode 输出：

- BaseOnly：forecast 与物理单位指标；
- horizon baseline：forecast 与物理单位指标；
- error-aware/PostHoc：forecast、risk、blend 与物理单位指标；
- 不再在 error-aware 日志中输出 `train_confidence=0` 或 `val_confidence=0`。

## 7. 验证顺序

1. 为 9 维特征写失败测试，确认旧实现产生 10 维重复输入；
2. 实现最小修正并运行 error-aware 测试；
3. 为模式化日志写失败测试；
4. 移除退出主线的执行分支并更新引用测试；
5. 验证当前 Latent48 checkpoint 和两个 Bank 可加载；
6. 运行全量 unittest、`compileall` 和 PowerShell 解析；
7. 用同一 frozen base、Bank 和 seed 重新训练 9 特征 PostHoc；
8. 记录删除路径、删除前大小、释放空间和不可恢复范围。

## 8. Keep / Remove / Stop

- 9 特征版本不劣于重复特征版本：保留 9 特征版本，删除旧 10 特征最终产物；
- Wide 相对 BaseCap 没有达到既定收益门槛：删除 Wide，保留 BaseCap；
- adapter 或 profile 旧入口仍被当前主线引用：停止删除该入口，先解除依赖并重新验证；
- 无法证明是派生产物或用途不明确：保留，不执行删除。
