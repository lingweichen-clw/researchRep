# STAnchor-BlockMemory v1 张量流审查

更新时间：2026-07-15

## 1. 静态契约

| 阶段 | 张量 | 维度 |
|---|---|---|
| 数据 | context | `(B,T,N,C)` |
| 数据 | future | `(B,H,N,C)` |
| 掩码 | patch mask | `(B,P,N)` |
| 掩码 | value mask | `(B,T,N,C)` |
| encoder | patch token | `(B,P,N,D)` |
| retrieval | node key | `(B,N,Dr)` |
| retrieval | event key | `(B,Dr)` |
| Bank | node keys | `(M,N,Dr)` |
| Bank | future values | `(M,H,N,C)` |
| 粗检索 | event ids | `(B,R)` |
| 精排 | node event ids/weights | `(B,N,K)` |
| 聚合 | candidate future | `(B,H,N,K,C)` |
| 聚合 | memory mean/variance | `(B,H,N,C)` |
| confidence | features | `(B,H,N,6)` |
| fusion | confidence/weight | `(B,H,N,1)` |
| 输出 | final | `(B,H,N,C)` |

所有非平凡 reshape、permute、edge gather 和候选 gather 都在模块边界检查 rank 与固定维度。

## 2. 已验证项目

- 节点 scaler 忽略缺失值，只读取训练段。
- 数据窗口的 context/future 完全位于各自时间 split 内。
- 时间 mask 在 `T=12,p=3` 时精确隐藏 1 个 patch，即 3 个时间步。
- 空间 mask 精确隐藏配置数量节点，每个被遮节点保留可见邻居。
- 全节点遮挡不会触发 first/last visible 越界。
- clean/masked 两分支共享 encoder，时间和空间任务均产生有限重建损失。
- retrieval loss 对 encoder 与 retrieval head 产生非零梯度。
- reconstruction loss 对 encoder 与 reconstruction head 产生非零梯度。
- mmap writer/reader 在 Windows 上显式关闭文件句柄。
- calendar 与 `future_end < context_start` 因果过滤可返回空候选。
- 空候选时 confidence、fusion weight 精确为 0，final 精确等于 base。
- 物理指标在目标 scaler inverse transform 后计算。
- METR-LA validation 的全局零值段已识别；完全无监督事件被排除，结构化 mask 只选择真实观测位置。

## 3. 真实 METR-LA smoke 证据

使用 `research` 环境与 `configs/metrla_v1.yaml`：

```text
raw series:      (34272,207,1)
context/future:  (32,12,207,1)
patch token:     (32,4,207,64)
node key:        (32,207,32)
event key:       (32,32)
smoke bank:      2016 events, 207 nodes, key dim 32
```

one-batch 预训练、建库、下游训练和 test 评估均已成功执行。smoke 只验证可运行性、张量流和有限值，不代表正式模型效果。

针对 2012-06-01 04:30 至 11:45 的全路网零值段，完整 validation 扫描结果为：原始 3404 个窗口中剔除 164 个无 context/future 监督窗口，剩余 3240 个窗口、102 个 batch 全部完成损失计算，`skipped_batches=0`。

## 4. 正式实验前仍需检查

- 用正式 50 epoch 预训练检查 retrieval positive/hard-negative 数量是否长期非零。
- 对 time/space mask 分别做 tiny-overfit 曲线，而不只检查单步梯度。
- 在完整目标 Bank 上统计 calendar 候选数、无候选率、coarse Recall@R。
- 报告 confidence 的 AUROC、AUPRC、Brier、ECE 与分桶真实 gain。
- 至少 3 个 seed；正式主表建议 5 个 seed。
- PEMS-BAY 文件就位后，先校验采样间隔、节点顺序、图节点数与 HDF 时间轴。
