# Patch1 连续时间遮挡实现计划

**目标：** 将时间编码 token 从 15 分钟粒度调整为 5 分钟粒度，同时保持每次时间预训练任务连续遮挡 15 分钟，形成可与现有 `patch_size=3` 基线直接比较的新实验。

**张量变化：**

```text
旧实验: x (B,12,N,1) -> token (B,4,N,64)，遮挡 1 token = 3 个原始时间步
新实验: x (B,12,N,1) -> token (B,12,N,64)，连续遮挡 3 token = 3 个原始时间步
```

## 实施步骤

1. 在 `PretrainConfig` 中增加原始时间步单位的 `time_mask_block_size`，并校验它能够被 `patch_size` 整除且不超过输入窗口。
2. 扩展 `StructuredMaskSampler`，按连续、不重叠的 token block 采样时间遮挡；空间遮挡逻辑保持不变。
3. 将参数传入 `STAnchorPretrainModel`，并在启动日志中打印遮挡块长度。
4. 新建 `configs/metrla_patch1_v1.yaml`，设置 `patch_size=1`、`time_mask_block_size=3`，使用独立 run name 和 Bank 目录。
5. 增加连续遮挡、配置校验和 patch1 完整前向/反向测试。
6. 更新 README 的训练命令，执行全部单元测试、编译检查和真实数据 one-batch 验证。

## 不变项

- 输入窗口与预测长度仍为 12 步。
- 时间遮挡信息量仍为连续 3 步。
- hidden dim、注意力头、encoder 层数、损失权重和数据切分保持不变。
- 原 `configs/metrla_v1.yaml` 与已有 checkpoint 不修改。
