# STAnchor-BlockMemory v1 实现说明

## 1. 实现边界

当前代码实现计划方案的第一版主流程：单源预训练、目标域整体重建 Bank、冻结检索 encoder、轻量下游模型、节点和 horizon 级 confidence、安全融合。可选 adapter 与近似向量索引保留为后续扩展，不进入 v1。

## 2. 预训练张量流

一个 source batch 同时构造 clean 与 masked 两个视图，二者共享 patch embedding 和时空 encoder：

```text
x_model:              (B,T,N,C)
clean token:          (B,P,N,D)
masked token:         (B,P,N,D)
concat encoder input: (2B,P,N,D)
clean hidden:         (B,P,N,D) -> node/event key
masked hidden:        (B,P,N,D) -> linear reconstruction -> (B,T,N,C)
```

时间任务遮挡 `k_t=floor(r_t*P)` 个完整 patch，并对所有节点使用相同 patch 位置。空间任务遮挡 `k_s=floor(r_s*N)` 个完整节点，并验证每个被遮节点至少有一个可见的一阶邻居。

clean 分支使用完整 context 窗口统计；masked 分支只用可见数值计算均值、标准差、最后值和首末差。整节点没有可见值时，数值目标退回数据集标准化坐标，level 输入替换为 unknown-level token。

完全没有 context 观测或完全没有 future 监督的事件在窗口数据集构造时排除。对其余自然缺失窗口，mask sampler 只从具有真实观测的 patch 或节点中选择重建目标；若极端 batch 同时没有重建位置和合法检索 anchor，训练引擎会记录并跳过该 batch。

## 3. 图注意力实现

空间注意力不构造 `(B,P,N,N)` 稠密分数。代码只在 `edge_index: (2,E)` 对应的道路边上计算 query-key 分数，并按 target node 执行 scatter softmax 和 value 聚合。所有节点在加载图时补充 self-loop，边索引范围和正权重会显式校验。

## 4. Bank 与检索

Bank 所有数组的第 0 维都是同一个 event ID。manifest 最后写入；缺少 manifest 的目录被视为不完整 Bank。节点 key、future 和 level 采用 `np.load(..., mmap_mode="r")`，事件 key 复制到 CPU/GPU 内存做精确点积。

检索顺序固定为：

```text
calendar exact bucket
-> future_end < query context_start
-> event top-R
-> node top-K within top-R
-> masked softmax weights
-> future value gather
-> valid-mask renormalized mean and variance
```

第一版不做末值平移、均值缩放或趋势对齐。

## 5. 下游与置信度

基础预测器是所有节点共享参数的 residual MLP，输入 `(B,T,N,C)`，输出 `(B,H,N,C)`。它不含节点 embedding，避免在目标节点集合变化时产生形状绑定。

confidence 输入严格由六类可观测诊断组成：最佳 shape score、top-1/top-2 margin、权重集中度、候选 future 方差、level match、memory/base 分歧。真实 future 仅在 calibration 阶段构造软监督标签。

最终融合为：

```text
weight = sigmoid(horizon_logit) * confidence * memory_valid
final  = base + weight * (memory - base)
```

因此 `memory_valid=False` 时 `weight` 在浮点计算上也是精确的 0，而不是接近 0。

## 6. Checkpoint 契约

预训练 checkpoint 保存：完整模型、encoder 子状态、retrieval 子状态、retrieval fingerprint、配置、source scaler、图指纹、epoch、seed 和指标。

下游 checkpoint 保存：backbone/confidence/fusion 状态、目标 scaler、Bank manifest、预训练 fingerprint、配置、epoch、seed 和指标。Bank 加载时还会比较目标图和目标 scaler。
