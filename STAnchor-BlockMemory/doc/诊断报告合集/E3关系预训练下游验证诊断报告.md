# E3 Future-Relation 预训练下游验证诊断报告

更新时间：2026-07-26

## 1. 本报告回答的问题

本报告只回答：

> E3 使用连续 future relation 监督替代 E2 的分位阈值监督后，检索改善能否进入 memory 分支，并进一步改善相同轻量下游模型的预测？

本报告仅使用 METR-LA validation 和下游随机种子 42，不使用 test，不据此选择 test 结果。

## 2. 结论先行

1. **E3 训练正常。** 下游训练在第 20 轮早停，最佳 checkpoint 位于第 10 轮；没有 NaN、Inf、Bank 不匹配或 confidence 异常。
2. **E3 改善了 Top-K，而没有改善 Top-1。** learned Top-1 future MAE 比 E2 高 0.0019，基本持平；uniform Top-K 和 weighted Top-K 分别改善 0.0300 和 0.0278。
3. **E3 的 Top-K 改善进入了下游 memory 分支。** `MemoryMAE` 从 3.82625 降到 3.80424，改善 0.02201；两组 memory coverage 都接近 100%。
4. **最终预测获得小幅收益。** overall MAE 从 3.22211 降到 3.21927，改善 0.00284；30、60 分钟 MAE 下降，15 分钟 MAE 仅退化 0.00136。
5. **改善不是 backbone 偶然变好。** E3 的 `BaseMAE` 反而比 E2 高 0.00644，但 `FinalMAE` 仍更低，证据指向 memory 与 fusion 的贡献。
6. **保留 E3 作为后续主线。** 原因不是单 seed 的 0.088% MAE 优势足够大，而是 E3 删除了 E2 的离散分位阈值，同时保持并小幅改善 Top-K 和下游 MAE，形成更好的“复杂度与效果”折中。
7. **当前不能宣称 E3 全面优于 E2。** E3 的 overall MAPE 高 0.0141，Top-1 没有改善，且尚未完成下游多随机种子验证。

## 3. E2 与 E3 的唯一机制差异

两版使用相同的一天历史 encoder、masked reconstruction、模型维度、图结构、Bank 规模、下游 backbone、Top-K 聚合、horizon-only fusion 和 seed。主要区别是 retrieval supervision。

E2 使用 future 距离与 context 距离的分位点生成离散 positive 和 hard negative。其局限是 `positive_quantile`、`context_quantile` 和 `negative_quantile` 会直接改变正负样本划分。

E3 不再把 pair 硬划分为 positive/negative，而是根据真实 future 距离构造连续教师分布。对 anchor $i$ 和合法历史候选 $j\in\mathcal V_i$：

\[
q^Y_{i,j}
=
\frac{
\exp\!\left(-d^Y_{i,j}/\tau_Y\right)
}{
\displaystyle\sum_{r\in\mathcal V_i}
\exp\!\left(-d^Y_{i,r}/\tau_Y\right)
}.
\]

其中：

- $d^Y_{i,j}$：anchor 与候选真实 future 的掩码距离；
- $\mathcal V_i$：不包含自身、时间不重叠且 future 有效的候选集合；
- $q^Y_{i,j}$：候选 $j$ 对 anchor $i$ 的 future 关系教师概率；
- $\tau_Y>0$：控制教师分布平滑程度的温度。

由 context node key 的相似度 $s^X_{i,j}$ 得到学生分布：

\[
p^X_{i,j}
=
\frac{
\exp\!\left(s^X_{i,j}/\tau_X\right)
}{
\displaystyle\sum_{r\in\mathcal V_i}
\exp\!\left(s^X_{i,r}/\tau_X\right)
}.
\]

E3 使用交叉熵使 $p^X$ 拟合 $q^Y$。它删除了离散分位阈值，但仍有 $\tau_Y$、$\tau_X$ 两个平滑温度；因此准确表述应是“减少离散样本划分敏感性”，而不是“完全没有超参数”。

## 4. 训练完整性检查

| 项目 | E2 | E3 |
|---|---:|---:|
| 下游模式 | learned Top-K + horizon-only | learned Top-K + horizon-only |
| 实际训练轮数 | 20 | 20 |
| 最佳轮次 | 10 | 10 |
| downstream trainable 参数 | 5,784 | 5,784 |
| frozen pretrained 参数 | 391,836 | 391,836 |
| validation 样本 | 2,993 | 2,993 |
| memory / calibration | 15,876 / 6,805 | 15,876 / 6,805 |
| node Top-K | 5 | 5 |
| confidence 参数 | 0 | 0 |

两组数据划分、样本数量、下游参数量和早停轮次完全一致，可以进行直接单变量比较。

`horizon-only` 不训练 confidence head。对第 $h$ 个预测步，最终预测为：

\[
\widehat Y^{\mathrm{final}}_{b,h,n,c}
=(1-\rho_h)\widehat Y^{\mathrm{base}}_{b,h,n,c}
+\rho_h\widehat Y^{\mathrm{mem}}_{b,h,n,c},
\qquad
\rho_h\in[0,1].
\]

$\rho_h$ 只随预测步变化，在样本和节点之间共享。因此日志中的 `val_confidence=0` 是预期行为。

## 5. 离线检索结果

所有 future MAE 都恢复到 METR-LA 原始速度尺度，并在诊断协议规定的共同有效位置计算，越低越好。

| 指标 | E2 | E3 | E3 - E2 | 判断 |
|---|---:|---:|---:|---|
| learned Top-1 future MAE | 4.263079 | 4.265001 | +0.001922 | 基本持平，E3 未改善第一名 |
| learned uniform Top-K future MAE | 3.953070 | **3.923117** | **-0.029954** | Top-K 候选集合改善 |
| learned weighted Top-K future MAE | 3.760028 | **3.732261** | **-0.027767** | 最终 memory 聚合改善 |
| Top-1 Oracle gap | 1.491797 | 1.497370 | +0.005572 | 没有缩小 |
| $K_{\mathrm{eff}}$ | 3.7465 | 4.4041 | +0.6576 | E3 权重更均匀 |

有效支持数定义为：

\[
K_{\mathrm{eff}}(b,n)
=
\frac{1}{\displaystyle\sum_{k=1}^{K}w_{b,n,k}^2},
\qquad 1\le K_{\mathrm{eff}}\le K.
\]

E3 的 $K_{\mathrm{eff}}$ 更接近 5，说明它没有把概率集中到单个候选。结合 uniform Top-K 的改善，E3 的主要作用是得到质量更好的候选集合和更平滑的候选关系，而不是强化 Top-1。

E2 和 E3 中 weighted Top-K 相对 uniform Top-K 的额外收益分别约为 0.1930 和 0.1909，基本相同。因此 E3 的新增收益主要来自候选集合，不是下游聚合器变化。

## 6. 下游预测结果

定义 E3 相对 E2 的相对改善：

\[
\operatorname{Gain}_{\mathrm{E3/E2}}
=
\frac{\operatorname{Error}_{\mathrm{E2}}-
\operatorname{Error}_{\mathrm{E3}}}
{\operatorname{Error}_{\mathrm{E2}}}
\times100\%.
\]

正值表示 E3 更好，负值表示 E3 退化。

### 6.1 Overall

| 指标 | E2 | E3 | E3 - E2 | 相对改善 |
|---|---:|---:|---:|---:|
| MAE | 3.222110 | **3.219274** | **-0.002836** | **+0.0880%** |
| RMSE | 6.348145 | **6.333624** | **-0.014521** | **+0.2287%** |
| MAPE | **9.165195%** | 9.179310% | +0.014115 | -0.1540% |

MAE 和 RMSE 改善，但幅度较小；MAPE 略微退化。因此 E3 的准确定位是“预测基本不退化并小幅改善 MAE/RMSE”，不是全面提高全部指标。

### 6.2 15/30/60 分钟

| Horizon | 指标 | E2 | E3 | E3 - E2 |
|---|---|---:|---:|---:|
| 15 分钟 | MAE | **2.781996** | 2.783356 | +0.001360 |
| 15 分钟 | RMSE | 5.394330 | **5.392873** | -0.001456 |
| 15 分钟 | MAPE | **7.441331%** | 7.465772% | +0.024441 |
| 30 分钟 | MAE | 3.254814 | **3.251902** | -0.002913 |
| 30 分钟 | RMSE | 6.425458 | **6.412666** | -0.012792 |
| 30 分钟 | MAPE | **9.209348%** | 9.220407% | +0.011060 |
| 60 分钟 | MAE | 3.830926 | **3.822934** | -0.007992 |
| 60 分钟 | RMSE | 7.436182 | **7.411068** | -0.025115 |
| 60 分钟 | MAPE | **11.619256%** | 11.624013% | +0.004758 |

E3 的 MAE/RMSE 收益随 horizon 总体增大，60 分钟最明显；MAPE 在三个标准 horizon 上都轻微退化。当前差异很小，必须用多随机种子判断方向是否稳定。

## 7. Base、Memory 与 Final 分支归因

三条预测均具有形状：

\[
\widehat{\mathbf Y}^{\mathrm{base}},
\widehat{\mathbf Y}^{\mathrm{mem}},
\widehat{\mathbf Y}^{\mathrm{final}}
\in\mathbb R^{B\times H\times N\times C}.
\]

- `BaseMAE`：最近 12 步轻量 backbone 的误差；
- `MemoryMAE`：只使用检索历史 future 聚合预测的误差；
- `FinalMAE`：两条分支经过 horizon-only fusion 后的误差；
- `MemoryGain = CommonBaseMAE - MemoryMAE`；
- `FinalGain = BaseMAE - FinalMAE`；
- gain 为正表示优于 base，为负表示单独使用 memory 更差。

| 指标 | E2 | E3 | E3 - E2 |
|---|---:|---:|---:|
| BaseMAE | **3.367145** | 3.373584 | +0.006440 |
| CommonBaseMAE | **3.366862** | 3.372997 | +0.006135 |
| MemoryMAE | 3.826251 | **3.804241** | **-0.022010** |
| MemoryGain | -0.459390 | **-0.431245** | **+0.028145** |
| FinalMAE | 3.222110 | **3.219274** | **-0.002836** |
| FinalGain | 0.145035 | **0.154310** | **+0.009275** |
| MemoryCoverage | 99.9967% | 99.9960% | -0.0006 个百分点 |

这是本轮最关键的归因证据：

1. E3 的 base 分支更差，不存在“E3 恰好把 backbone 训练得更好”这一解释；
2. E3 的 memory 分支改善 0.02201；
3. 两组 coverage 几乎相同，MemoryMAE 改善不是通过避开困难位置获得；
4. E3 的 FinalGain 比 E2 多 0.00928，说明更好的 memory 被融合器利用。

虽然两版 `MemoryGain` 都为负，即 memory 单独预测不如 base，但这不与 FinalGain 为正矛盾。融合使用：

\[
\widehat Y^{\mathrm{final}}
=
\widehat Y^{\mathrm{base}}
+\rho_h
\left(
\widehat Y^{\mathrm{mem}}-
\widehat Y^{\mathrm{base}}
\right).
\]

memory 的整体 MAE 可以更高，但其误差方向在部分位置能够抵消 base 的误差；只注入约 40% 的 memory 残差后，最终结果仍可能优于两条单独分支。当前证据支持“memory 是有噪声但具有互补信息的校正源”，不支持“memory 可以单独替代预测 backbone”。

## 9. 去留决定

### 9.1 后续主线保留 E3

保留 E3 Future-Relation 作为后续预训练主线，理由是：

1. 删除 E2 的三组离散分位阈值，目标定义更连续；
2. Top-K 候选质量和 weighted memory MAE 均改善；
3. 下游 MAE/RMSE 没有因简化监督而退化，反而小幅改善；
4. 参数量、训练时间量级、建库与推理接口都没有增加。

### 9.2 E2 的定位

E2 不再作为后续功能扩展的主线，但必须保留为论文中的 hard-label/quantile ablation。E3 “减少阈值依赖”的论点只有在与 E2 的相同协议对照中才成立，不能删除 E2 的正式结果。

### 9.3 当前不能宣称的结论

- 不能宣称 E3 显著提高预测精度；当前 MAE 改善只有 0.088%；
- 不能宣称 E3 改善 Top-1 selector；Top-1 实际略差；
- 不能宣称 E3 全指标更优；MAPE 略有退化；
- 不能宣称预训练对随机种子稳定；当前预训练 checkpoint 仍只有 seed 42；
- 不能运行 test 或根据 test 继续调结构。

## 10. 下一步实验

下一步只关闭一个不确定性：

> E3 相对 E2 的小幅 horizon-only 收益，是否能够跨下游随机种子保持方向一致？

执行配对的 seed 2024、2025 下游实验。每个 seed 必须同时运行 E2 与 E3；虽然未来主线只扩展 E3，但 E2 仍是判断 E3 threshold-free 替代是否成立的必要对照。

保留标准：

1. E3 三 seed 平均 overall MAE 不高于 E2；
2. 30、60 分钟平均 MAE 不出现系统性退化；
3. E3 的平均 MemoryMAE 低于 E2；
4. 若 E3 仅与 E2 持平，也可以因删除分位阈值而保留，但论文只能声称“简化并保持性能”，不能声称“稳定提升精度”。

在该配对多 seed 完成前，不训练新的 confidence 网络，不改 encoder，也不增加新模块。
