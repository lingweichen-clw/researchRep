# E5 项目压缩与主线精炼清理报告

## 1. 清理边界

本轮清理保留正式主线 `Global288 + Latent48 + OffsetDecay + SymNorm`，以及当前 pretrained/random Latent48 Bank、BaseOnly、受控归因和 PostHoc 实验。这里，PostHoc 指先冻结已经训练完成的基础预测模型，再单独训练检索诊断与残差修正模块；训练和推理均不读取真实未来值作为输入。E2、E3、E5A 与 Local12 的结论性 checkpoint、日志和报告继续作为论文演进证据保留。

退出活动主线的机制包括 CFDP/profile key、CC-FGDA、Trend Residual T0 和旧六特征 `learned_topk_confidence`。旧配置中的零值字段仅在当前 checkpoint 加载确有需要时保留，不再构造废弃网络或打印无意义指标。
