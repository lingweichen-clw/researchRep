# E3 关系预训练下游三随机种子诊断报告

## 1. 诊断问题

本报告只回答一个问题：在冻结预训练编码器和检索库后，E3 Future-Relation 相比 E2 day-96 的下游收益，是否能够跨下游随机初始化稳定保持。

对照严格使用相同的：

- 数据集与 validation 划分：METR-LA；
- 下游模式：`learned_topk_horizon`，即 horizon-only fusion；
- 下游网络参数量：总参数 6,041，可训练参数 5,784；
- 检索设置：`event_top_r=32`、`node_top_k=5`；
- 下游随机种子：42、2024、2025；
- 早停指标：validation overall MAE。

唯一变化是预训练 checkpoint 及其对应 Bank：E2 使用离散 future 阈值版，E3 使用 Future-Relation 软关系学习版。

## 2. 统计口径

设方法为 (m\in\{\mathrm{E2},\mathrm{E3}\})，下游随机种子为 (s\in\{1,2,3\})，指标为 (x_{m,s})。三次结果的均值为：

\[
\bar{x}_{m}=\frac{1}{3}\sum_{s=1}^{3}x_{m,s}.
\]

样本标准差为：

\[
\operatorname{Std}(x_m)
=
\sqrt{\frac{1}{3-1}\sum_{s=1}^{3}\left(x_{m,s}-\bar{x}_m\right)^2}.
\]

其中，(x_{m,s}) 是方法 (m) 在第 (s) 个下游随机种子上的 validation 指标。本文表格中的“均值 ± 标准差”均采用上述样本标准差。

为了排除同一随机初始化造成的波动，主要判断量是逐 seed 配对差：

\[
\Delta_s(x)=x_{\mathrm{E3},s}-x_{\mathrm{E2},s}.
\]

对于 MAE、RMSE 和 MAPE，\(\Delta_s(x)<0\) 表示 E3 更好。MAE 相对改善率定义为：

\[
G_s^{\mathrm{MAE}}
=
\frac{\operatorname{MAE}_{\mathrm{E2},s}-\operatorname{MAE}_{\mathrm{E3},s}}
{\operatorname{MAE}_{\mathrm{E2},s}}
\times 100\%.
\]

## 3. Overall 结果

| 指标 | E2 day-96 | E3 relation | 配对差 E3 - E2 | 判断 |
|---|---:|---:|---:|---|
| MAE | 3.221222 ± 0.001923 | **3.218329 ± 0.001669** | **-0.002893 ± 0.000311** | E3 三个 seed 均更低 |
| RMSE | 6.384290 ± 0.042848 | **6.374059 ± 0.047382** | **-0.010230 ± 0.004569** | E3 三个 seed 均更低 |
| MAPE (%) | **9.162244 ± 0.027383** | 9.172200 ± 0.023557 | +0.009957 ± 0.005784 | E3 三个 seed 均略高 |

E3 的平均 MAE 相对改善率为：

\[
\overline{G^{\mathrm{MAE}}}=0.0898\%\pm0.0096\%.
\]

这个改善方向非常稳定，但绝对幅度只有约 0.0029 MAE，不能解释为显著精度突破。MAPE 又出现了方向一致的小幅退化，因此准确表述应是：**E3 稳定小幅改善 MAE/RMSE，但没有全面改善三类误差。**

## 6. Memory 与融合分支诊断

horizon-only 模式没有样本级 confidence。设：

- \(\widehat{\mathbf Y}^{\mathrm{base}}\in\mathbb R^{B\times H\times N\times C}\)：当前窗口经下游 backbone 得到的预测；
- \(\widehat{\mathbf Y}^{\mathrm{mem}}\in\mathbb R^{B\times H\times N\times C}\)：Top-K 历史 future 聚合后的 memory 预测；
- \(a_h\in(0,1)\)：第 \(h\) 个预测步的可学习融合权重；
- \(B,H,N,C\)：batch 大小、预测步数、节点数和输出通道数。

最终预测为：

\[
\widehat{Y}^{\mathrm{final}}_{b,h,n,c}
=
\widehat{Y}^{\mathrm{base}}_{b,h,n,c}
+a_h\left(
\widehat{Y}^{\mathrm{mem}}_{b,h,n,c}
-\widehat{Y}^{\mathrm{base}}_{b,h,n,c}
\right).
\]

| 指标 | E2 day-96 | E3 relation | 配对差 E3 - E2 |
|---|---:|---:|---:|
| BaseMAE | **3.366225 ± 0.001119** | 3.371564 ± 0.002475 | +0.005339 ± 0.001356 |
| MemoryMAE | 3.826251 ± 0.000000 | **3.804241 ± 0.000000** | **-0.022010 ± 0.000000** |
| FinalGain | 0.145004 ± 0.000976 | **0.153235 ± 0.000977** | **+0.008232 ± 0.001560** |
| 平均 fusion weight | 0.352990 ± 0.047626 | 0.358692 ± 0.049679 | +0.005702 ± 0.002057 |

`FinalGain` 定义为：

\[
\operatorname{FinalGain}
=
\operatorname{MAE}_{\mathrm{base}}
-\operatorname{MAE}_{\mathrm{final}}.
\]

它为正表示融合后的预测优于该次训练得到的 base 分支。

关键结论有三点：

1. E3 的 `MemoryMAE` 比 E2 低 0.022010，说明关系预训练改善确实进入了历史记忆分支。
2. 两种方法的 `MemoryMAE` 都明显高于各自 `BaseMAE`。历史 memory 不能单独替代当前窗口预测；它目前只适合作为残差补充。
3. E3 的 base 分支反而平均差 0.005339，但最终 MAE 仍更低，且 `FinalGain` 更大。这表明 E3 的最终小幅收益主要来自更好的 memory 及融合，而不是 backbone 偶然变强。

所有下游 seed 都复用同一个 E2 预训练 checkpoint/Bank 和同一个 E3 预训练 checkpoint/Bank。因此 `MemoryMAE` 在不同下游 seed 下几乎完全相同是预期行为，**不能把它表述为三次独立预训练复现**。目前验证的是下游初始化稳定性，不是预训练 seed 稳定性。

## 8. 最终判断

### 8.1 保留什么

**保留 E3 Future-Relation 作为后续主线，E2 作为离散阈值消融。**

依据是：

- E3 在三个 seed 上都改善 overall MAE 和 RMSE；
- 30、60 分钟 MAE 在三个 seed 上都改善；
- E3 的固定 memory 分支 MAE 明确低于 E2；
- E3 避免 E2 的 positive/context/negative quantile 离散阈值，方法更连续、更容易泛化；
- 参数量和下游训练成本没有增加。

### 8.2 不能宣称什么

当前不能宣称“E3 显著提高预测精度”，原因是：

- MAE 相对改善只有约 0.09%；
- MAPE 在三个 seed 上都略差；
- 只有三个下游 seed，不适合做强统计显著性结论；
- 预训练 checkpoint 仍只有一个 seed；
- raw memory 仍弱于 base，memory 价值依赖融合器。

更准确的论文表述是：**Future-Relation 软关系预训练以更少的人工阈值获得稳定的小幅 MAE/RMSE 改善，并提升了历史 memory 的质量，构成优于 E2 的简化 Pareto 解。**

### 8.3 下一步唯一实验

现在可以进入 E3 `learned_topk_confidence` 的 seed=42 单变量实验，只回答：样本级 confidence 是否比当前 horizon-only 权重更能抑制有害 memory。

保留 confidence 必须同时满足：

- final MAE 低于 E3 horizon-only seed=42；
- AUROC 大于 0.5；
- AUPRC 大于 helpful-memory prevalence；
- Brier score 低于 constant-confidence Brier；
- confidence 四分位 memory gain 总体随置信度上升。

若不满足，就删除 confidence 主模块并保留 horizon-only fusion。此阶段仍禁止查看 test，也不再调整 encoder、关系损失、Top-K 或融合温度。
