# E2、E3、E5A 检索可视化诊断报告

## 1. 结论先行

本实验验证了一个具体机制问题：预训练 selector 是否真的把“未来模式相似”的历史事件映射到了更近的 node key。三版都在完全相同的 validation query、合法历史候选池和 Bank 事件轴上比较 pretrained 与 random。结果显示：

- E2、E3、E5A 的 pretrained key-future Spearman 秩相关和 Future-Neighbor Recall@5 均高于 random；
- key-distance 从近到远的 10 个等频区间中，teacher-aligned future distance 总体上升，说明 key 空间不是随机的；
- E3 的关系对齐增益最大（Spearman +0.208488），但 memory MAE 增益只有 0.900%，说明“全局关系更好”不等于“部署 Top-5 预测收益等比例增加”；
- E5A 的最终 OffsetDecay memory 误差最好，且同一 pretrained selector 下 RawFuture 到 OffsetDecay 的 MAE 下降约 7.345%，说明轻量 payload 对齐是当前预测收益的重要来源。

因此阶段 2 的决策是：**Keep as mechanism evidence**。预训练 selector 可以作为 future-guided retrieval 的机制证据保留；不因为本实验再增加趋势分解、confidence head、cross-attention 或新 backbone。当前结论来自单个 seed 42，不能写成统计显著性结论。

## 2. 实验动机与边界

交通预测中，两个历史 context 可能处于不同的 level 或局部状态，但它们之后的 future 变化却相似。这种“历史相似不保证未来相似”的错配是本项目所说的时空海市蜃楼问题。普通历史匹配只按 history key 检索，无法证明 key 真正编码了 future relation。

本实验不训练新模型，只读取已有 checkpoint、历史 Bank 和 validation split。每个 query 的历史、日历信息、因果候选 Bank 元数据、历史 Bank key 和历史 Bank level 可以用于部署排序；query 的真实 future 只在排序完成后用于离线距离、误差、确定性选例和画图。它不进入 key 编码、候选过滤、Top-K 排序、检索权重或 memory 预测。

正式 validation 统计：每个版本 2,993 个 query、94 个 batch；pretrained 和 random 的合法候选事件轴、future payload、节点数（207）完全一致。候选池平均 8.014 个，范围 5--9 个。有效 pair 数为 E2/E3 的 4,850,134，E5A 的 4,748,149。

## 3. 术语、输入输出与计算

### 3.1 合法历史候选集合

**合法历史候选集合**是对一个 query 保证部署可用的 Bank 事件集合。候选需满足相同星期和时刻约束，并且候选 future 已在 query context 开始前完全发生。输入是 query 的 calendar、context start 和 Bank 的 causal metadata；输出是候选事件编号集合。该过程不读取 query future。

### 3.2 Node key 与 KeyDistance

每个 query-node 的历史编码器输出一个 node key。query key 为 \(k_q\in\mathbb{R}^{D}\)，候选事件的对应 node key 为 \(k_j\in\mathbb{R}^{D}\)。**KeyDistance**（node-key 距离）是衡量两个 key 方向差异的距离：

\[
d^{key}_{qjn}=1-\cos(k_{q,n},k_{j,n}).
\]

输入形状为 query key `[B,N,D]`、候选 key `[B,R,N,D]` 和候选有效 mask `[B,R]`；输出为 `[B,N,R]`。\(B\) 是 batch size，\(N\) 是节点数，\(R\) 是当前 query 的合法候选数，\(D\) 是 key 维度。距离越小表示 selector 认为两个历史事件越相似。它只使用历史编码器和 Bank key，不使用 query future。

### 3.3 E2/E3 的 ContextNormalizedFutureSignature

**ContextNormalizedFutureSignature**（上下文归一化未来表示）是 E2/E3 teacher 用来定义 future relation 的离线表示。对事件 \(i\)，令 future 为 \(Y_i\in\mathbb{R}^{H\times N\times C}\)，context 为 \(X_i\in\mathbb{R}^{T_c\times N\times C}\)，本实验 \(H=12\)、\(T_c=288\)、\(C=1\)。按 context 时间轴计算每个 node/channel 的均值 \(\mu_i\) 和标准差 \(\sigma_i\)，然后：

\[
S^{ctx}_{i,h,n,c}=\frac{Y_{i,h,n,c}-\mu_{i,n,c}}
{\sigma_{i,n,c}+\varepsilon}.
\]

对 query 与候选在共同有效观测位置上计算 masked MAE，得到 teacher-aligned future distance \(d^{future}_{qjn}\in\mathbb{R}\)，汇总输出为 `[B,N,R]`。它在本实验中只用于排序完成后的评价；训练 teacher 可以读取训练事件 future，部署推理不能读取 query future。

### 3.4 E5A 的 DeploymentAlignedOffsetDecaySignature

**DeploymentAlignedOffsetDecaySignature**（部署对齐的 OffsetDecay 未来表示，简称 ODSignature）是 E5A teacher 学习的 future signature。令 \(\alpha_{i,n,c}\) 为事件 \(i\) 预测起点前 context 的末端 level，\(\lambda_h\) 为随 horizon 从近端 1 线性衰减到远端 0 的系数，则：

\[
S^{OD}_{i,h,n,c}=Y_{i,h,n,c}-\lambda_h\alpha_{i,n,c}.
\]

它把推理时的 level 对齐形式直接写入 teacher 的关系对象。与 E2/E3 相同，对共同有效位置计算 masked MAE；E5A 还执行 **AnchorMeanDistanceNormalization**（按 anchor 的候选平均距离归一化）：对同一 `(query,node)` 的有效候选距离除以该 anchor 候选距离均值加 \(\varepsilon\)。这样去除物理单位尺度差异，同时保留候选的距离排序。E5A 的 alignment 只应在 E5A 内比较 pretrained 和 random，不能把其 Spearman 绝对值直接与 E2/E3 比较，因为 teacher signature 和归一化不同。

### 3.5 Key-Future Alignment

**Key-Future Alignment**（key 与未来关系对齐）是把 KeyDistance 与 teacher-aligned future distance 放在同一候选对上比较。若 key 越近的候选 future distance 越小，说明历史 key 空间学习到了目标 future relation。

将所有有效 `(query,node,candidate)` 对按 KeyDistance 从小到大分成 10 个等频 decile（每个区间约含相同 pair 数），统计每个区间的 future distance 均值和中位数，形成曲线。近端到远端总体上升，是最直观的图形证据。

### 3.6 Spearman 秩相关

**Spearman 秩相关** \(\rho\) 是两个变量排序的一致性，而不是物理误差。对有效 pair 的 KeyDistance 和 future distance 分别取秩，再计算 Pearson 相关：

\[
\rho=\operatorname{corr}(\operatorname{rank}(d^{key}),
\operatorname{rank}(d^{future})).
\]

输入是两组同形状 `[B,N,R]` 的有效距离，输出一个标量 \([-1,1]\)。\(\rho>0\) 表示 key 越远通常 future 越不相似；越大表示全局秩关系越一致。该指标使用 query future 作为离线评价标签，不参与部署。

### 3.7 Future-Neighbor Recall@5

**Future-Neighbor Recall@5** 是“key 找到的 5 个近邻”覆盖“future distance 定义的 5 个近邻”的比例。对候选数至少为 6 的每个 anchor：

\[
R@5=\frac{|\operatorname{Top5}_{key}\cap
\operatorname{Top5}_{future}|}{5}.
\]

先在候选池中按 KeyDistance 和 future distance 各取 5 个，再对 eligible anchor 求平均。因为本实验候选池平均约 8 个，绝对 Recall@5 偏高，所以重点解释 pretrained 相对 random 的差值，不能把 0.74 直接写成“检索准确率 74%”。该指标只用于离线诊断。

### 3.8 Memory MAE、RMSE、MAPE

**Memory** 是对 Top-5 历史候选 future payload 按 selector 权重聚合得到的 `[B,H,N,C]` 预测。对有效物理速度元素集合 \(\Omega\)，真实 future 为 \(Y\)，memory 为 \(\widehat Y\)：

\[
\mathrm{MAE}=\frac{1}{|\Omega|}\sum_{(h,n,c)\in\Omega}|\widehat Y-Y|,
\]
\[
\mathrm{RMSE}=\sqrt{\frac{1}{|\Omega|}\sum_{(h,n,c)\in\Omega}(\widehat Y-Y)^2},
\]
\[
\mathrm{MAPE}=\frac{100}{|\Omega_{\%}|}\sum_{(h,n,c)\in\Omega_{\%}}
\left|\frac{\widehat Y-Y}{Y}\right|.
\]

MAPE 的集合 \(\Omega_{\%}\) 还排除分母过小或无效观测。三项指标都在交通速度物理单位（MAE/RMSE）或百分比（MAPE）上统计；它们使用 query future，但只在检索之后计算。

### 3.9 Deterministic Top-5 Cases

**Deterministic Top-5 Cases**（确定性 Top-5 案例）不是手工挑图。对每个共同有效 query-node，先用各自部署排序和 Top-5 权重形成 pretrained/random memory，再计算：

\[
\Delta MAE=MAE_{random}-MAE_{pretrained}.
\]

最接近 \(\Delta MAE\) 的 90%、50%、10% 分位点分别固定命名为 `strong_win`、`representative`、`failure`；并要求该 query-node 的所有 horizon/channel 都有有效观测。选择规则、sample id、node id、候选 id 和权重写入 `cases.json`，保证可复现。未来只用于排序完成后的案例选择和画图。

### 3.10 E5A 的 RawFuture 与 OffsetDecay memory

**RawFuture memory** 是直接对候选历史 future 做加权平均：

\[
\widehat Y_h^{raw}=\sum_{j\in K_q}w_{qj}\,Y_{j,h}.
\]

**OffsetDecay** 不是额外神经网络，而是对同一批候选做 level 对齐并随 horizon 衰减：

\[
\widehat Y_h^{OD}=\widehat Y_h^{raw}+
\lambda_h(\widehat Y_h^{offset}-\widehat Y_h^{raw}).
\]

输入是 query context、候选 context 的末端 level、候选 future 和同一组检索权重；输出 `[B,H,N,C]`。推理只读取 query history 和已发生的 Bank 历史，不读取 query future。E5A payload 案例独立按 `RawFuture MAE - OffsetDecay MAE` 的 90%、50%、10% 分位点选择，不能与 selector 对比案例混用。

## 4. 正式结果

### 4.1 Key-Future Alignment

| Version | Selector | Spearman \(\rho\) | Recall@5 | 有效 pair |
|---|---|---:|---:|---:|
| E2 | pretrained | 0.546628 | 0.746138 | 4,850,134 |
| E2 | random | 0.417814 | 0.690372 | 4,850,134 |
| E3 | pretrained | 0.626302 | 0.744761 | 4,850,134 |
| E3 | random | 0.417814 | 0.690372 | 4,850,134 |
| E5A | pretrained | 0.318104 | 0.737649 | 4,748,149 |
| E5A | random | 0.160026 | 0.697929 | 4,748,149 |

E2 的 pretrained 相对 random 增益为 \(\Delta\rho=+0.128814\)、\(\Delta R@5=+0.055766\)；E3 为 `+0.208488`、`+0.054389`；E5A 为 `+0.158078`、`+0.039720`。三版 decile 曲线均总体由近到远上升：pretrained 的首/末 decile future distance 分别为 E2 `0.2722 -> 2.4945`、E3 `0.2424 -> 2.5852`、E5A `0.8283 -> 1.3900`。这支持“更近 key 对应更相似 future”的方向性关系。E5A 数值尺度经过 ODSignature 和 AnchorMeanDistanceNormalization，不能与 E2/E3 的绝对距离或 \(\rho\) 直接横向比较。

### 4.2 Memory 物理误差

| Version | Selector/payload | MAE | RMSE | MAPE (%) |
|---|---|---:|---:|---:|
| E2 | pretrained memory | 3.826123 | 7.494589 | 10.501591 |
| E2 | random memory | 3.868767 | 7.501767 | 10.696392 |
| E3 | pretrained memory | 3.855423 | 7.431364 | 10.710211 |
| E3 | random memory | 3.890435 | 7.484586 | 10.765350 |
| E5A | pretrained OffsetDecay memory | 3.527230 | 6.604164 | 9.331257 |
| E5A | random OffsetDecay memory | 3.667355 | 6.786500 | 9.723048 |

相对 random 的 MAE 改善为 E2 `1.102%`、E3 `0.900%`、E5A `3.821%`。E5A 中固定 pretrained selector 后，RawFuture MAE `3.806840` 降至 OffsetDecay `3.527230`，payload 单独改善约 `7.345%`；因此 E5A 的最终收益不能全部归因于 selector，必须把“关系学习”和“部署对齐 payload”分开报告。

### 4.3 确定性案例

每个版本都输出 `strong_win`、`representative` 和 `failure` 三个自动选择案例。它们分别代表预训练相对 random 明显获益、典型中位情况和预训练失败，不是 cherry-picking。E5A 另有独立 payload 案例：`strong_win` 的 RawFuture 到 OffsetDecay MAE 改善 `0.963539`，`representative` 改善 `0.000227`，`failure` 下降 `-0.486307`。这说明 OffsetDecay 是总体有效的轻量校正，但并非每个事件都改善，不能只展示成功图。

## 5. 结果传达的科学信号

### 5.1 预训练确实改变了 key 空间

三版 pretrained 都同时提高 Spearman 和 Recall@5，并且 decile 曲线总体上升。这排除了“预训练只是换了一个随机坐标系”的解释，支持 future-guided selector 学到了可检验的 future relation。

### 5.2 关系对齐和部署预测收益不是同一个量

E3 的 Spearman 增益最大，但 memory MAE 改善略低于 E2。这说明全局 key 的秩结构变好，不保证部署时有限候选池、Top-5 截断和 payload 聚合的物理误差按相同比例下降。论文中不能只展示 Spearman，也不能只展示最终 MAE；两类证据必须并列。

### 5.3 E5A 说明 payload 对齐是关键瓶颈

E5A 的 selector 相对 random 有正向关系信号，但最大的物理误差下降来自 RawFuture 到 OffsetDecay。也就是说，当前系统的核心贡献应表述为“future-guided selector 学 relation + deployment-aligned OffsetDecay 将历史 future 转换为适合当前 level 的 memory payload”，而不是声称庞大检索模块单独贡献了全部收益。

### 5.4 失败案例的意义

`failure` 案例是预先规定的低分位案例。它证明方法不是所有时空状态都有效，可能受候选池稀疏、突发事件、level 非平稳或 Top-5 截断影响。保留失败案例能防止把单个成功图误写成普遍规律，也为后续误差分析提供可复现实例。

## 6. Keep / Remove / Stop

- **Keep**：E2、E3、E5A 的 pretrained-vs-random alignment 证据、确定性案例图；E5A 的 RawFuture-vs-OffsetDecay 独立 payload 证据。
- **Keep with limited claim**：E3 作为“关系学习最强”的消融版本，但不把其较大的 Spearman 增益等同于最大预测收益。
- **Do not add**：趋势分解、confidence head、cross-attention、新 backbone。当前证据已经定位到 selector relation 和 payload 对齐两个可解释因素，继续堆模块不会关闭新的不确定性。
- **Next verification**：在不读取 test 的前提下完成三版本 random、可视化报告归档和第二下游宿主；只有当跨宿主方向一致时，才扩大“模型无关检索增强”的论文主张。正式论文最终仍需冻结版本后再运行 test，并补充多 seed 方差。
