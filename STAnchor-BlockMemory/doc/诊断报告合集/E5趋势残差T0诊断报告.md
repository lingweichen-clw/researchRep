# E5 Future-Guided 趋势残差 T0 诊断报告

> 日期：2026-08-02  
> 结论级别：validation 机制诊断，不是最终 test 结果  
> 核心结论：删除局部线性趋势外推和局部尺度搬运；保留零参数的 horizon-decayed query-level alignment，进入 T1 future-guided 关系预训练验证。

## 1. 本轮回答的问题

T0 不重新预训练、不修改 Bank schema、不接入 confidence，也不更换 downstream backbone。它只回答：在当前 E3 learned retrieval 的同一候选集合、同一 node Top-K 和同一权重下，改变 retrieved future 的坐标表达是否能产生独立收益。

因此本轮能够区分：

1. 收益是否来自 future payload，而不是 confidence；
2. level offset、线性 trend 和 local scale 三种因素中，哪一种值得保留；
3. learned future-guided selector 是否优于固定的历史 Pearson selector；
4. 该机制是否同时在 METR-LA 同域与 PEMS-BAY 跨域成立。

本轮不回答 E5 新 teacher 是否优于 E3 teacher；该问题属于 T1。

## 2. 实验契约与未来边界

- Query context：`[B,12,N,C]`；
- Candidate context：`[B,R,12,N,C]`；
- Candidate future：`[B,H,N,R,C]`；
- Bank 候选继续满足 `candidate.future_end < query.context_start`；
- 可部署方法只读取 query history、训练历史 Bank 和 calendar metadata；
- Query future 仅用于离线指标、future oracle 和 past-future rank correlation；
- PEMS-BAY Bank 只包含 PEMS-BAY training history，迁移的是 METR-LA E3 relation encoder；
- 所有主结果都不使用 confidence。

正式资产：

- METR-LA checkpoint：`artifacts/metrla_e3_relation_seed42/pretrain_best_relation.pt`；
- METR-LA Bank：`artifacts/metrla_bank_e3_relation_relation`；
- PEMS-BAY Bank：`artifacts/pemsbay_bank_from_metrla_e3_relation`；
- METR-LA 结果：`artifacts/e5_t0_metrla_val.json`；
- PEMS-BAY 结果：`artifacts/e5_t0_pemsbay_val.json`。

Checkpoint/Bank 指纹经过严格校验。`pretrain_best.pt` 对应 `_total` Bank，`pretrain_best_relation.pt` 才对应 `_relation` Bank；本轮没有绕过该校验。

## 3. 被比较的方法

| 方法 | 排序 | future payload | 可部署 |
|---|---|---|---|
| `learned_raw_topk` | 当前 E3 relation node key | raw future | 是 |
| `learned_offset_topk` | 与 raw 完全相同 | query-local level residual | 是 |
| `learned_offset_decay_topk` | 与 raw 完全相同 | horizon-decayed level alignment | 是 |
| `learned_trend_topk` | 与 raw 完全相同 | query-local level + linear trend residual | 是 |
| `fixed_offset_topk` | history offset Pearson | level residual | 是 |
| `fixed_trend_topk` | history trend-residual Pearson | trend residual | 是 |
| `future_oracle_trend_top1` | query future | trend residual | 否，仅诊断 |

其中零参数衰减版本为

\[
\widehat Y^{\mathrm{decay}}_{q,h}
=
\widehat Y^{\mathrm{raw}}_{q,h}
+\lambda_h
\left(
\widehat Y^{\mathrm{offset}}_{q,h}
-\widehat Y^{\mathrm{raw}}_{q,h}
\right),
\qquad
\lambda_h=1-\frac{h-1}{H-1}.
\]

因此第一步完整采用 query-local level alignment，最后一步严格回到 raw retrieved future。它没有参数、gate 或额外网络。

## 4. 首次 smoke 暴露的尺度失败

原始方案将 candidate future 除以 candidate-local 一阶差分 RMS，再乘 query-local RMS。该设计在真实 METR-LA batch 中出现：

- query local scale 最小值约 `0.001`，最大值约 `4.151`；
- candidate local scale 的 0.1% 分位数已经落到 `0.001`；
- `query_scale / candidate_scale` 最大约 `4151`；
- reconstructed model value 最大约 `14812`；
- offset/trend RMSE 因少量极端值达到约 `877`。

这不是 inverse transform、缺失 mask 或 future 对齐错误，而是 local scale transfer 的结构性不稳定：平坦历史的 candidate 可以在未来发生正常变化，除以接近零的历史变化尺度会产生无界残差。

决策：

- **Remove local scale transfer**；
- 不增加 scale clip、MAD、可学习 scale gate 等补丁；
- T0 的 payload 使用 unit scale，只隔离 level 和 trend；
- scale 估计工具保留为诊断代码，不进入候选模型。

## 5. 完整 validation 结果

所有 deployable 方法在共同有效 mask 上计算物理量指标。METR-LA 共 `2993` 个 query，common coverage 为 `0.989883`；PEMS-BAY 共 `4912` 个 query，common coverage 为 `0.995572`。

| Dataset | Method | MAE | RMSE | MAE gain vs raw |
|---|---|---:|---:|---:|
| METR-LA | learned raw | 3.8027 | 7.3721 | 0.00% |
| METR-LA | learned offset | 3.8940 | 7.0904 | -2.40% |
| METR-LA | **learned offset decay** | **3.6231** | **6.7349** | **+4.72%** |
| METR-LA | learned trend | 5.3743 | 10.2662 | -41.33% |
| METR-LA | fixed offset | 4.6700 | 8.4326 | -22.81% |
| METR-LA | fixed trend | 6.9380 | 13.5007 | -82.45% |
| METR-LA | future oracle trend Top-1 | 3.5198 | 7.1205 | +7.44% |
| PEMS-BAY | learned raw | 2.2028 | 4.5774 | 0.00% |
| PEMS-BAY | learned offset | 1.9782 | 4.1377 | +10.19% |

## 6. Horizon 证据

完整 offset 的作用明显随预测距离衰减：

- METR-LA：H1 改善 `12.80%`，H2 改善 `6.61%`，H4 仅改善 `0.70%`，H5 起转为负收益，H12 恶化 `9.48%`；
- PEMS-BAY：H1 改善 `40.56%`，之后单调减弱，H11 仅改善 `0.27%`，H12 恶化 `0.75%`。

这说明当前 query level 是很强的近端条件，但不应被完整平移到整个 60 分钟 horizon。线性衰减不是任意调参，而是由两套数据相同的 horizon 失效模式直接导出的零参数修正。

## 7. 排序能力与核心创新的关系

Past-future Spearman 排名相关均很低：

| Dataset | Offset history vs future | Trend history vs future |
|---|---:|---:|
| METR-LA | 0.0818 | 0.0316 |
| PEMS-BAY | 0.1139 | 0.0659 |

固定 Pearson 的 offset/trend 方法在两个数据集都劣于 learned raw；而同一个 learned E3 selector 加上 offset decay 后在两个数据集都提升。这组对照支持两个判断：

1. 仅靠手工历史趋势相似度不能替代 learned future-guided relation；
2. 当前 E3 selector 已包含有用关系，但 raw future payload 没有把它充分转化为预测收益。

这与本工作的主创新方向一致：核心不是“检索几个 future 后交给 confidence”，而是用 future 在训练期定义有意义的历史关系，并让检索到的 future 以 query-compatible 的形式直接产生无 confidence 收益。

## 8. 与前人工作的边界

本轮同时核对了本地论文和官方源码：

- **RAFT** 已使用 final-offset removal、Pearson similarity、多粒度检索和后续 value patch，因此“减去末值”本身不是创新；
- **SARAF** 使用 dataset-level stationarity、time-aligned similarity、MMR diversity 与 adaptive Gaussian weighting，但没有本项目的 future-guided relation pretraining 和 node/instance-level target-local future memory；
- **PIR** 根据预测不确定性做 local/global post-forecasting revising，与 confidence/校准更接近，不能用来证明 retrieval representation 有效；
- **RAST** 检索 learned spatial/temporal embeddings 后送入 backbone，不是 target-local residual future payload；
- **STWave+ / TimeMixer** 的分解机制更复杂，T0 已经证明线性 trend 外推有害，因此当前没有引入 DWT、DFT 或双分支的证据。

当前最多只能提出以下**候选组合创新**：

> 在同物理变量的跨域交通预测中，用 future relation 监督历史检索表示，并将因果历史 Bank 中的 future memory 通过 node/instance-level、horizon-decayed query-level alignment 映射到当前 query，使检索模块在不依赖 confidence 的情况下产生可测收益。

其中 offset、线性衰减和 memory retrieval 单独都不能声称新颖。该组合必须经过 T1 预训练和无 confidence 下游实验后才能成为论文贡献。

## 9. Keep / Remove / Stop

### Keep

- future-guided learned retrieval 主线；
- unit-scale query-local level residual；
- zero-parameter horizon decay；
- causal target-local Bank；
- future oracle 和 rank correlation 仅作为诊断。

### Remove

- candidate/query local scale transfer；
- 完整 horizon 的恒定 level 平移作为最终版本；
- fixed Pearson selector 作为候选主模型。

### Stop

- E5 linear trend branch；
- STWave+/TimeMixer 式复杂趋势分解；
- GCRU backbone 复现；
- 在 T1 前接入 confidence 或 E4 目标域适配。

## 10. 唯一下一步：T1 OffsetDecay Future Relation

T1 只修改 future teacher，不改 downstream 和 candidate sampling。定义 offset future：

\[
u^{Y,\mathrm{offset}}_{i,h,n,c}=y_{i,h,n,c}-\alpha_{i,n,c}.
\]

以同一个无参数 horizon 权重构造 teacher distance：

\[
d^{\mathrm{OD}}(i,j)
=
\frac{
\sum_{h,n,c}\lambda_h\,\mathcal O_{ijhnc}
\left|u^{Y,\mathrm{offset}}_{i,h,n,c}-u^{Y,\mathrm{offset}}_{j,h,n,c}\right|
}{
\sum_{h,n,c}\lambda_h\,\mathcal O_{ijhnc}+\epsilon
}.
\]

只比较：

1. E3 relation teacher；
2. E5 OffsetDecay teacher；
3. source random encoder；
4. fixed history-offset Pearson。

T1 保留条件：E5 必须同时改善 METR-LA 和 PEMS-BAY 的 retrieval 指标，并在不带 confidence 的下游模式中优于 E3 与 random。任何一项不成立都停止 E5，不增加 backbone。
