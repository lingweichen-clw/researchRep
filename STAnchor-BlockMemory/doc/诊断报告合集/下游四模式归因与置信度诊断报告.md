# STAnchor 下游历史来源与置信度诊断报告

> 状态说明：本文保留为 seed 42 的阶段性诊断。最终结构选择请以《下游三随机种子归因与置信度诊断报告》为准。

## 1. 诊断范围

本报告只使用 METR-LA 的 validation split，对五个 `seed=42` 正式实验的最佳 checkpoint 进行统一评估。没有查看 test split，因此以下结论用于模型筛选，不能直接作为论文最终性能结论。

五组实验分别为：

| 编号 | 模式 | 历史信息与融合方式 |
|---|---|---|
| A | `base_only` | 只使用当前 12 步输入，不使用历史库 |
| B | `weekly_mean_horizon` | 同 weekday-slot 历史未来均值，使用 horizon-only fusion |
| C | `raw_l1_topk_horizon` | 按原始上下文 L1 距离检索 Top-K，使用 horizon-only fusion |
| D | `learned_topk_horizon` | 按预训练 key 检索 Top-K，使用 learned 聚合和 horizon-only fusion |
| E | `learned_topk_confidence` | D 的历史来源，再加入节点级 confidence 与安全融合 |

所有组使用相同数据切分、下游 backbone、训练 seed 和正式 memory bank：

- 预训练 checkpoint：`artifacts/metrla_pretrain_seed42/pretrain_best.pt`，最佳 epoch 为 18；
- memory bank：`artifacts/metrla_bank_v1`；
- 验证样本窗口数：3240；
- batch 数：102；
- 时间分辨率：5 分钟；
- 预测长度：12 步，即 60 分钟。

## 2. 指标定义

设第 $h$ 个预测步上的真实值为 $y_{i,h}$，预测值为 $\hat{y}_{i,h}$，该预测步有效观测的数量为 $M_h$。下标 $i$ 合并表示 batch、节点和通道。

### 2.1 MAE

\[
\operatorname{MAE}_h
=
\frac{1}{M_h}
\sum_{i=1}^{M_h}
\left|\hat{y}_{i,h}-y_{i,h}\right|.
\]

MAE 表示平均绝对预测误差，越小越好。

### 2.2 RMSE

\[
\operatorname{RMSE}_h
=
\sqrt{
\frac{1}{M_h}
\sum_{i=1}^{M_h}
\left(\hat{y}_{i,h}-y_{i,h}\right)^2
}.
\]

RMSE 对大误差更敏感，越小越好。

### 2.3 MAPE

设 $M_h^{+}$ 是真实值绝对值大于数值阈值的有效位置数量，则

\[
\operatorname{MAPE}_h
=
\frac{100\%}{M_h^{+}}
\sum_{i=1}^{M_h^{+}}
\frac{\left|\hat{y}_{i,h}-y_{i,h}\right|}{\left|y_{i,h}\right|}.
\]

MAPE 表示相对误差百分比，越小越好。当前实现排除接近零的真实值，避免分母不稳定。

METR-LA 每步为 5 分钟，因此：

- 15 分钟对应第 3 个预测步；
- 30 分钟对应第 6 个预测步；
- 60 分钟对应第 12 个预测步。

## 4. 核心判断

### 4.1 历史信息有效，但不能直接替代当前窗口预测

B、C、D、E 的整体 MAE 都优于 A，说明历史信息确实提供了当前 12 步输入之外的有效上下文。最简单的 weekly mean 已把 MAE 降低 2.01%，因此“历史周期模式对 METR-LA 无效”这一假设可以排除。

但是，E checkpoint 的分支诊断显示：

- 当前窗口 backbone 单独预测的 MAE 为 3.4322；
- 检索历史未来直接作为预测的 MAE 为 3.9689；
- 安全融合后的 MAE 为 3.2209。

这说明检索结果不是一个可以独立工作的高质量预测器。当前正确定位应当是：历史库提供辅助残差信息，当前窗口 backbone 仍然是主预测分支。

### 4.2 learned selector 有收益，但优势尚不足以单 seed 定案

D 相对 C 的整体 MAE 改善为

\[
\frac{3.3016-3.2873}{3.3016}\times 100\%
=0.43\%.
\]

该值落在原计划的 $0.2\%$ 至 $0.5\%$ 灰区：

- learned retrieval 比 raw L1 有一致的小幅收益；
- 但收益不足以证明复杂的 learned selector 必然值得保留；
- 按既定规则，只需要对 C、D 做多 seed，不应继续增加新的检索模块。

分预测长度看，D 相对 C 的 MAE 改善为：15 分钟 0.50%，30 分钟 0.59%，60 分钟 0.23%。learned selector 的优势没有随预测长度稳定扩大。

检索诊断还显示，learned Top-K 历史未来 MAE 为 3.9047，而 Oracle Top-1 为 2.7977，两者相差 1.6391 MAE。这里的 Oracle 使用真实未来误差选择候选，只表示候选库中可达到的理想上界，推理时不可使用。较大的 Oracle 差距说明候选库包含有价值模式，但当前 key 排序仍没有充分识别它们。

### 4.3 confidence 通过单 seed 筛选，但识别能力仍然偏弱

E 相对 D 的整体 MAE 改善为

\[
\frac{3.2873-3.2209}{3.2873}\times 100\%
=2.02\%.
\]

分预测长度的 MAE 改善为：

- 15 分钟：0.73%；
- 30 分钟：1.22%；
- 60 分钟：4.10%。

收益随预测长度增大，说明 confidence fusion 主要改善长预测步，而不是简单修饰短期预测。

confidence 的目标定义为“该节点、该预测步上，memory prediction 是否比 base prediction 更接近真实值”。现有诊断结果为：

| 指标 | 数值 | 判断 |
|---|---:|---|
| AUROC | 0.5575 | 高于随机 0.5，但区分能力较弱 |
| AUPRC | 0.4986 | 高于正例率 0.4528，但优势有限 |
| Brier score | 0.24714 | 略优于常数基线 0.24777 |
| Brier 相对改善 | 0.26% | 概率校准收益很小 |

按预先制定的筛选规则，E 的 MAE 改善超过 0.5%，AUROC 高于随机，Brier 也优于常数基线，因此 confidence 可以保留进入多 seed 验证。但不能声称 confidence 已经学到强判别能力。

四分位诊断进一步显示，最高 confidence 四分位中的 memory gain 为 +3.17%，而前三个四分位仍为负。这说明 confidence 能把一部分有效历史模式推向高分区域，但排序边界仍然不够清晰。

### 4.4 E 没有明显改善整体 RMSE

E 的整体 MAE 和 MAPE 最优，但 RMSE 为 6.4712，略差于 B 的 6.4514。说明当前方法主要减少常见样本的绝对误差和相对误差，对少量大误差样本的改善不明显。

因此下一轮不应继续堆叠结构。更合理的是在多 seed 中同时检查 MAE 与 RMSE：如果 E 只能稳定改善 MAE、却持续不能改善 RMSE，需要把论文表述限制为“改善平均预测质量和长时域误差”，而不是“全面提升鲁棒性”。

## 5. 当前决策

### 5.1 保留

- 历史 memory 分支：B/C/D/E 均证明历史上下文有下游价值；
- confidence fusion：E 相对 D 改善 2.02%，通过单 seed 筛选；
- 15/30/60 分钟 horizon 指标：必须作为后续所有正式训练和评估的固定输出。

### 5.2 暂不定案

- learned selector：D 相对 C 只改善 0.43%，必须通过 C/D 多 seed 决定是否值得保留预训练检索头。

### 5.3 不做

- 不增加新的 selector、对齐模块、额外 attention 或新损失；
- 不查看 test split；
- 不用单个 seed 宣称显著优于 ST-SSDL 或其他论文结果。
