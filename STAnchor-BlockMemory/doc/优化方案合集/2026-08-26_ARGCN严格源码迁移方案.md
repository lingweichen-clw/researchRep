# ARGCN（AGCRN-compatible）严格源码迁移方案

## 1. 目的与边界

本次迁移的目标是把 ST-SSDL 源码中的可复用 AGCN/AGCRN 基础骨干接入主线，形成一个独立的时空预测 baseline，用于验证 TGGE 作为插件是否能适配不同下游模型。这里的 `argcn` 是项目配置键；模型本体明确称为 **AGCRN-compatible baseline**，不把完整 ST-SSDL 当作 ARGCN。

## 2. 保留的官方组件

按照 `ST-SSDL/model_STSSDL/STSSDL.py`，保留以下计算链：

`AGCN → AGCRNCell → ADCRNN Encoder → multi-horizon projection`。

- **AGCN**：对每个静态图 support 构造 Chebyshev 基 `[I,S,2S^2-I,...]`，聚合节点特征并线性映射。
- **AGCRNCell**：`[x,h]` 经过 AGCN gate 得到更新门和重置门，再经 AGCN update 生成候选状态。
- **ADCRNN Encoder**：按时间步展开 AGCRNCell，按层堆叠，输出最后时间步节点状态。
- **预测头**：对每个节点的最终隐藏状态一次性投影为 `H×C_out`，输出 `[B,H,N,C_out]`，与主线接口一致。

默认配置保持源码关键值：`hidden_dim=128`、`num_layers=1`、`cheb_k=3`、输入/输出通道由数据集配置决定。

## 3. 明确排除的 ST-SSDL 专属分支

以下内容不进入独立 baseline：prototype/Wq、历史正负 prototype 对照、hypernet 动态邻接、STSSDL 专用 decoder、课程学习和对比学习损失。这样才能把下游性能归因于 AGCN/AGCRN 骨干，而不是完整 ST-SSDL。

## 4. 主线适配

主线输入为 `[B,T,N,C]`，输出为 `[B,H,N,C]`。`target.py` 仍构造并传入一个行归一化静态 support，以保持统一图数据接口；模型不生成动态 support。

## 5. 验证与停止标准

迁移后必须依次通过：

1. `py_compile` 编译检查；
2. 单 batch forward，检查输出形状和有限值；
3. 单 batch backward，检查所有梯度有限；
4. 参数量与结构记录（单 support、128 hidden、1 层、K=3 约 150,540 参数）。

只有上述检查全部通过后，才提供正式训练命令；smoke 产物不作为论文实验结果。
