# 2026-09-07 目标域检索编码器微调最终方案

## 一、最终决策

本轮微调对象是 HN-OffsetDecay 检索编码器，不是下游 Router，也不是四个 backbone。采用参数高效、逐步解冻的目标域适配：先冻结主干训练检索头和域适配分支；只有关系指标仍不足时，才解冻最后一层空间交互模块。默认不进行全模型微调。

当前跨数据集结果已经证明 source encoder 存在可迁移信号，但强度有差异：PEMS-BAY 和 PEMS04 中 source key 优于 random，PEMS08 中 source 与 random 接近。因此结论是“需要目标域适配”，而不是“所有参数都应该更新”。

## 二、与近期预训练工作的对应关系

近两年时间序列和时空预训练工作的迁移阶段没有单一统一做法，但有稳定共识：

1. TimesFM、Chronos、Moirai 等先报告 zero-shot 或 frozen encoder，再根据目标数据量决定是否微调。
2. MOMENT 等工作将冻结编码器、训练任务头作为低成本适配基线，并与全量微调区分。
3. 时空基础模型常使用 dataset/domain adapter、prompt 或其他参数高效更新，避免小目标域破坏通用表示。
4. 当目标路网和邻接关系变化时，空间交互模块比早期输入嵌入更需要适配；早期时间表示通常保持冻结。
5. 预训练权重迁移使用明显小于预训练的学习率，并采用逐步解冻。

这些工作的可复用结论是：先用冻结基线和轻量 adapter 测量域偏移来源，再局部调整空间模块，而不是直接全模型重训。

## 三、模型、数据和未来信息边界

检索输入和节点 key 为：

\[
x^{ret}\in\mathbb{R}^{B\times288\times N\times1},\qquad
z\in\mathbb{R}^{B\times N\times64}.
\]

Bank 中保存节点 key：

\[
Z^{bank}\in\mathbb{R}^{M\times N\times64}.
\]

288 步历史只能来自 query 时刻之前。目标域 train split 的 future 可用于 HN-OffsetDecay relation teacher；validation/test future 只能用于离线评估和 early stopping，不能进入 query key、候选选择或 Bank 构建。

保持不变：retrieval context=288、forecast context=12、horizon=12、`weekday_radius1_overlap`、`event_top_r=96`、`node_top_k=12`、target train-only scaler、Bank schema、Router 和四个 backbone。

PEMS-BAY、PEMS04、PEMS08 属于同物理变量 speed 迁移。PEMS07 是 flow，单独作为 exploratory speed-to-flow transfer，不纳入本轮主结论。

## 四、微调损失

目标域训练 batch 沿用现有 HN-OffsetDecay relation teacher：

\[
\mathcal{L}_{rel}=\operatorname{CE}
\left(q^{teacher}_{HN\text{-}OD},q^{student}_{key}\right).
\]

T1 冻结编码器与重构头后，重构分支不经过任何可训练参数，因此 T1 总损失为：

\[
\mathcal{L}_{T1}=1.0\mathcal{L}_{rel}+0.05\mathcal{L}_{distill}.
\]

- `L_rel` 是主损失，使目标域 key 排序贴近目标域 future relation；
- `L_distill` 是源表示保持项。对同一个目标历史，冻结 source encoder 得到 `z_src`，微调模型得到 `z_ft`：

\[
\mathcal{L}_{distill}=1-\cos(\operatorname{sg}(z_{src}),z_{ft}).
\]

`sg` 只阻断 source teacher 的梯度，不阻断目标模型。该项不使用 future，不构成部署泄漏。T1 不计算 `L_recon`，避免记录一个对 T1 参数没有梯度的伪辅助分支；若进入 T3 并解冻编码块，再单独评估是否恢复重构约束。不加入新的 relation projection、usage balance 或额外 contrastive loss。

## 五、逐步解冻协议

### T0：source-only 冻结基线

不更新检索参数，直接用 METR-LA source checkpoint 在目标域 train events 建立 Bank，并在 validation 上测量关系指标。T0 是所有微调阶段的严格对照。

### T1：检索头和域适配分支

冻结 `embedding`、全部 `encoder.blocks` 和 `reconstruction_head`；解冻：

- `retrieval_head.pool_projection`；
- `retrieval_head.pool_score`；
- `retrieval_head.key_mlp`；
- `retrieval_head.domain_adapter`。

这一步只改变“如何将目标域隐藏状态组织为 key”，不改变主时空编码器。

建议配置：

```yaml
adaptation:
  stage: head_adapter
  epochs: 8
  batch_size: 16
  learning_rate: 3.0e-4
  weight_decay: 1.0e-4
  relation_weight: 1.0
  distill_weight: 0.05
```

### T2：加入最后一层空间交互

只有 T1 未达到保留标准时执行。继续训练 T1 参数，并额外解冻最后一个 `FactorizedSTBlock` 的 `spatial_attention`、`route_attention` 及其直接相连的空间归一化/门控参数。保持 `embedding`、前 3 层 block、最后一层 temporal attention、最后一层 FFN 和 reconstruction head 冻结。

```yaml
head_lr: 1.0e-4
spatial_lr: 3.0e-5
weight_decay: 1.0e-4
epochs: 8
```

T2 的物理含义是适配目标路网的邻接、传播方向和局部空间扩散模式，同时保留 source 的时间基础表示。

### T3：最后完整编码块的保守解冻

T3 不是默认阶段，仅在 T2 的关系指标改善但 Router 仍无改善时执行一次。额外解冻最后一个完整 block，学习率降为：

```yaml
head_lr: 5.0e-5
last_block_lr: 1.0e-5
epochs: 5
```

前 3 个 block 和 embedding 永不解冻。T3 是本项目的最大解冻范围，不做全模型微调。

## 六、每次微调后必须重建 Bank

只要 encoder 或 retrieval head 更新，旧 Bank 的 key 就失效。每个阶段都必须：

1. 用阶段最佳 checkpoint 在目标域 train events 上重新编码；
2. 生成新的 target Bank；
3. 校验 checkpoint fingerprint、graph fingerprint 和 scaler state；
4. 在 validation 上计算 relation case study；
5. 再进行下游 Router 验证。

不能用微调后的 query key 配 source-only candidate Bank，否则 query/candidate 不在同一表示空间，结果没有解释意义。

## 七、验证指标和顺序

固定验证链：

```text
T0 source-only -> T1 head + adapter -> T2 + final spatial block -> T3 optional
```

每阶段保持相同 split、scaler、candidate protocol、event_top_r、node_top_k、seed、future trend 定义、base checkpoint 和 Router 训练预算。

训练期间每轮计算目标域 validation 上的 HN-OffsetDecay relation loss、teacher/student effective support、有效 anchor 数和候选对数，并以 `val_relation` 选择 T1 checkpoint。

微调结束后必须先用最佳 checkpoint 重建目标域 Bank，再在真实 `weekday_radius1_overlap` 候选池上计算 query-level Key-Future Spearman、Future cosine@1/3/5/8/12、Oracle recall@1/3/5/8/12、coverage 和 candidate pool size。这样不会把 batch 内 broad-causal teacher 指标误写成部署协议指标。

下游层指标：Base-only、source-only Bank + Router、adapted Bank + Router 的 MAE、RMSE、MAPE、15/30/60 分钟指标，以及训练时间、峰值显存和可训练参数量。

训练内 checkpoint 选择指标是 validation relation loss；阶段保留判断的主指标仍是重建 Bank 后的 validation query-level Spearman，Future cosine@12 作为并列指标。test 只在最终策略确定后评估一次。

## 八、保留和停止标准

T1 至少满足以下两项且没有明显退化才保留：Spearman 提升至少 0.01；Future cosine@1 或 @12 提升至少 0.01；Oracle recall@12 提升至少 0.02；下游 MAE 改善至少 0.01；或 PEMS08 这类 source/random 接近的域出现稳定正向变化。

若 T1 无效而目标域图结构差异明显，进入 T2。T2/T3 必须同时改善 relation 指标和下游 MAE，且 PEMS-BAY、PEMS04 的 MAE 退化不得超过 0.005。

停止条件：连续两个阶段不超过 T0；relation 改善但 Router MAE 退化超过 0.01；key 分布塌缩或 oracle recall 下降；validation relation 在 2--3 个 epoch 后持续下降；或 Bank fingerprint/scaler 不匹配。

## 九、第一轮实验范围

第一轮做 seed=42 筛选：PEMS04 运行 T0/T1/T2，PEMS08 运行 T0/T1/T2，PEMS-BAY 先运行 T1；只有 T1 在至少两个目标域满足保留标准，才对选定策略做 seed=42/2024/2025 确认。

论文中可准确表述为：

> We adapt the retrieval representation to each target traffic domain using a parameter-efficient staged protocol. The retrieval head and domain adapter are updated first, followed by the final spatial interaction block when residual graph-related shift remains. Early temporal representations remain frozen to reduce overfitting and catastrophic forgetting.
