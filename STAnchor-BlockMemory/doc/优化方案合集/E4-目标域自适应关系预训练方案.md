# E4 目标域自适应关系预训练方案

## 1. 方案依据

同域归因已经确认：

- METR-LA 上 E3 source 优于 random；
- PEMS-BAY 上 E3 source 不如 random；
- 删除 `level_weight` 后 source 更差；
- 因此当前主要问题是跨数据集表示域偏移，而不是候选策略或 level 分数。

E4 不再收缩预训练候选，不新增 Transformer、图模块、adapter 或 confidence 分支。唯一改动是：

> 用目标数据集的训练段继续执行已有 E3 自监督任务，使 source encoder 在保持原有 future-relation 能力的同时适应目标域。

这对应时空预训练中的目标域自适应预训练，而不是使用目标 validation/test 做监督微调。

## 2. 三组正式对照

在实施三组目标域适配前，先完成一个不训练的 Stage 0：使用 random seeds 42、2024、2025 分别构建 METR-LA random Bank，并在默认 `level_weight=0.25` 下运行完整 validation 检索诊断。

设三个 random seed 的 weighted Top-K MAE 为 $M^{(1)}_{\mathrm{rand}},M^{(2)}_{\mathrm{rand}},M^{(3)}_{\mathrm{rand}}$，则计算：

$$
\overline{M}_{\mathrm{rand}}
=
\frac{1}{3}\sum_{r=1}^{3}M^{(r)}_{\mathrm{rand}},
$$

$$
S_{\mathrm{rand}}
=
\sqrt{
\frac{1}{2}
\sum_{r=1}^{3}
\left(M^{(r)}_{\mathrm{rand}}-\overline{M}_{\mathrm{rand}}\right)^2
}.
$$

其中 $\overline{M}_{\mathrm{rand}}$ 是 random 检索 MAE 均值，$S_{\mathrm{rand}}$ 是三个 random initialization 的样本标准差。

- 若 source MAE 低于三个 random seed，继续目标域适配；
- 若 source 只优于 seed 42、但落入 random seeds 的正常波动范围，则不能确认 E3 同域预训练贡献，暂停 E4 适配；
- Stage 0 不训练任何模型参数，预计成本仅为两套额外 random Bank 和 validation 诊断。

### Stage 0 实际结果：通过

| 指标 | E3 source | Random 三种子均值 | Random 样本标准差 | Source 相对改善 |
|---|---:|---:|---:|---:|
| learned Top-1 MAE | **4.265001** | 4.343271 | 0.005076 | 1.802% |
| learned uniform Top-K MAE | **3.923116** | 3.976352 | 0.004319 | 1.339% |
| learned weighted Top-K MAE | **3.732261** | 3.789223 | 0.007136 | 1.503% |

Source 在三项指标上均优于 random seeds 42、2024、2025。因此 Stage 0 通过，可以实施 source-to-target adapted 与 target-random adapted 的目标域预训练对照。

### A. Source-frozen

直接使用 METR-LA E3 checkpoint 在 PEMS-BAY 构建 Bank。

这是已经完成的基线：

$$
\operatorname{MemoryMAE}=2.209414.
$$

### B. Source-to-target adapted

以 METR-LA E3 checkpoint 初始化，在 PEMS-BAY **训练段**继续运行当前 E3 预训练任务：

$$
\theta_{\mathrm{adapt}}
=
\operatorname{Pretrain}_{\mathrm{E3}}
\left(
\theta_{\mathrm{source}},
\mathcal D^{\mathrm{PEMS}}_{\mathrm{train}}
\right).
$$

其中：

- $\theta_{\mathrm{source}}$：METR-LA E3 encoder 和 retrieval head 参数；
- $\mathcal D^{\mathrm{PEMS}}_{\mathrm{train}}$：PEMS-BAY 训练段；
- 不使用 PEMS-BAY validation/test 的 future 监督；
- 继续使用现有 masked reconstruction 和 future relation loss。

### C. Target-random adapted

以 target-random checkpoint 初始化，用完全相同的 PEMS-BAY 训练段、epoch 数、batch size 和学习率运行相同的 E3 预训练任务。

这一步用于判断收益究竟来自：

- source checkpoint 提供了可迁移初始化；还是
- 只要在目标域预训练，任何初始化都可以学到同样的表示。

## 3. 为什么不直接改候选集合

当前 E3 的训练目标是让 future 相似的 context 在隐藏空间接近：

$$
d^Y_{i,j,n}\text{ 小}
\quad\Longrightarrow\quad
\cos(\mathbf k_{i,n},\mathbf k_{j,n})\text{ 大}.
$$

如果强制所有候选满足同 weekday-slot，则会删除跨时段但具有相似动态 future 的训练关系，可能使模型学习周期桶内排序，而不是学习通用的未来动态模式。

E4 先保持原候选策略不变，把唯一不确定性收敛到目标域适配。只有当目标域继续预训练仍然无法超过 random，才重新考虑候选设计。

## 4. 训练张量流

PEMS-BAY 每个事件输入为：

$$
\mathbf X\in\mathbb R^{B\times288\times N\times C},
$$

其中 $B$ 是 batch size，288 是一天历史步数，$N=325$ 是节点数，$C=1$ 是速度通道。

编码器输出节点 key：

$$
\mathbf K\in\mathbb R^{B\times N\times48}.
$$

后续仍使用当前 E3 关系损失：

$$
\mathcal L_{mathrm{E3}}
=
\mathcal L_{mathrm{mask}}
+
\lambda_r\mathcal L_{mathrm{relation}}.
$$

E4 不改变 key 的维度、候选定义、teacher/student temperature 或 loss weight。

## 5. 工程改动

当前 `scripts/pretrain.py` 只能从随机初始化开始训练，需要增加一个可选参数：

```text
--init-checkpoint <path>
```

加载流程为：

1. 根据目标域 config 构建模型；
2. 读取 source 或 random checkpoint；
3. 严格检查 model/retrieval fingerprint 和 tensor shape；
4. 只加载 `model_state_dict` 或 encoder/retrieval state；
5. 目标域重新创建 optimizer 和 scheduler；
6. 重新记录目标域 normalizer、graph fingerprint、初始化 checkpoint 和 seed。

不加载源域 optimizer 状态，避免把源域动量带入目标域。

## 6. 最小实验设置

Stage 0 已通过。适配首轮只运行 seed 42，保持当前 E3 主要超参数不变：

- `patch_size=12`；
- `hidden_dim=96`；
- `retrieval_dim=48`；
- `encoder_layers=3`；
- `retrieval_loss_mode=relation`；
- `level_weight=0.25`；
- target pretraining epochs 先使用 10；
- 使用 PEMS-BAY train split，不能读取 validation/test future。

10 epoch 不是最终超参数，而是第一轮适配成本控制。若 source-to-target 在 10 epoch 已明显改善，再追加 25/50 epoch；若没有改善，不继续扩大 epoch。

## 7. 评价指标

### 检索层

比较三组的：

- learned Top-1 future MAE；
- learned uniform Top-K future MAE；
- learned weighted Top-K future MAE；
- Oracle 与 learned 的差距；
- Top-1 weight 和 $K_{\mathrm{eff}}$。

### 下游层

先只运行 `learned_topk_horizon`，比较：

- validation MAE；
- validation RMSE；
- validation MAPE；
- 15、30、60 分钟 MAE。

暂时不训练 confidence，因为 selector 改变后原 confidence head 不能直接复用。

## 8. 决策规则

- 若 source-to-target adapted 同时优于 source-frozen 和 target-random adapted 的 retrieval weighted Top-K，并且下游 MAE 至少改善 `0.5%`，保留目标域自适应作为正式迁移流程。
- 若 source-to-target adapted 优于 source-frozen，但不优于 target-random adapted，说明目标域预训练有效，但 source 初始化没有额外价值；论文中不能声称 source pretraining 带来迁移收益。
- 若 source-to-target adapted 与 source-frozen 持平，说明短期目标域适配没有解决问题；停止增加结构，优先检查 key/domain statistics。
- 若三组都接近，停止继续扩展 E3 source-transfer 主线，保留历史 memory 作为独立模块，转向更简单的目标域训练基线。

## 9. 复杂度边界

本方案只增加一次已有预训练流程在目标训练集上的继续运行，不增加推理参数和检索时延。若适配阶段不能带来明确收益，立即停止，不再增加 domain adapter、对抗域对齐或多源联合预训练。

## 10. 当前不做的实验

- 不将预训练候选限制为同 weekday-slot；
- 不扫描 `level_weight`；
- 不使用 PEMS-BAY validation/test 进行适配；
- 不运行 PEMS-BAY 多 seed；
- 不重新训练 confidence，直到 selector 方案确定。
