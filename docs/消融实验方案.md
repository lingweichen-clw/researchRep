# ST-SSDL 消融实验方案

更新时间：2026-06-03

## 1. 实验目的

对照 ST-SSDL 论文的消融实验，验证自监督偏差学习框架中各组件的实际贡献。论文消融项包括：

| 实验名 | 关闭内容 | 当前代码开关 |
|---|---|---|
| ST-SSDL full | 不关闭组件 | `--model baseline` |
| w/o `L_Con` | 原型三元组对比损失 | `--no-contrastive-loss --lamb-c 0` |
| w/o `L_Dev` | 当前序列与历史锚点的偏差一致性损失 | `--no-deviation-loss --lamb-d 0` |
| w/o `L_Con`, w/o `L_Dev` | 两个自监督损失 | `--no-contrastive-loss --no-deviation-loss --lamb-c 0 --lamb-d 0` |
| w/o SSDL | 整个 SSDL 原型/历史偏差模块 | `--no-ssdl --no-contrastive-loss --no-deviation-loss --lamb-c 0 --lamb-d 0` |

当前新增开关位置：

```text
TrafficRobustST/src/train.py
TrafficRobustST/src/losses.py
TrafficRobustST/src/models/stssdl_baseline.py
```

## 4. 执行命令

### 4.1 Full

```powershell
python -m src.train --model baseline --processed-dir data\METRLA --epochs 200 --patience 30 --batch-size 128 --device cuda:0 --seed 999 --rnn-units 128 --prototype-dim 64 --prototype-num 20 --input-embedding-dim 3 --tod-embed-dim 20 --node-embedding-dim 25 --adaptive-embedding-dim 0 --lamb-c 0.01 --lamb-d 1 --lr-scheduler multistep --lr-milestones 50,70 --lr-decay-ratio 0.1 --output-dir log --run-name metrla_stssdl_full
```

### 4.2 w/o `L_Con`

```powershell
python -m src.train --model baseline --processed-dir data\METRLA --epochs 200 --patience 30 --batch-size 128 --device cuda:0 --seed 999 --rnn-units 128 --prototype-dim 64 --prototype-num 20 --input-embedding-dim 3 --tod-embed-dim 20 --node-embedding-dim 25 --adaptive-embedding-dim 0 --no-contrastive-loss --lamb-c 0 --lamb-d 1 --lr-scheduler multistep --lr-milestones 50,70 --lr-decay-ratio 0.1 --output-dir log --run-name metrla_stssdl_wo_lcon
```

观察重点：原型是否更容易坍塌，整体 MAE/RMSE 是否退化。

### 4.3 w/o `L_Dev`

```powershell
python -m src.train --model baseline --processed-dir data\METRLA --epochs 200 --patience 30 --batch-size 128 --device cuda:0 --seed 999 --rnn-units 128 --prototype-dim 64 --prototype-num 20 --input-embedding-dim 3 --tod-embed-dim 20 --node-embedding-dim 25 --adaptive-embedding-dim 0 --lamb-c 0.01 --no-deviation-loss --lamb-d 0 --lr-scheduler multistep --lr-milestones 50,70 --lr-decay-ratio 0.1 --output-dir log --run-name metrla_stssdl_wo_ldev
```

观察重点：15min 与 60min 的变化是否不同。若 60min 退化更明显，说明偏差一致性更偏向长预测泛化。

### 4.4 w/o `L_Con`, w/o `L_Dev`

```powershell
python -m src.train --model baseline --processed-dir data\METRLA --epochs 200 --patience 30 --batch-size 128 --device cuda:0 --seed 999 --rnn-units 128 --prototype-dim 64 --prototype-num 20 --input-embedding-dim 3 --tod-embed-dim 20 --node-embedding-dim 25 --adaptive-embedding-dim 0 --no-contrastive-loss --no-deviation-loss --lamb-c 0 --lamb-d 0 --lr-scheduler multistep --lr-milestones 50,70 --lr-decay-ratio 0.1 --output-dir log --run-name metrla_stssdl_wo_lcon_ldev
```

观察重点：保留原型 value 注入但去掉自监督约束后，预测是否仍然受益。

### 4.5 w/o SSDL

```powershell
python -m src.train --model baseline --processed-dir data\METRLA --epochs 200 --patience 30 --batch-size 128 --device cuda:0 --seed 999 --rnn-units 128 --prototype-dim 64 --prototype-num 20 --input-embedding-dim 3 --tod-embed-dim 20 --node-embedding-dim 25 --adaptive-embedding-dim 0 --no-ssdl --no-contrastive-loss --no-deviation-loss --lamb-c 0 --lamb-d 0 --lr-scheduler multistep --lr-milestones 50,70 --lr-decay-ratio 0.1 --output-dir log --run-name metrla_stssdl_wo_ssdl
```

观察重点：关闭 SSDL 后，decoder 不再拼接 prototype value，自适应图也不再使用当前/历史原型偏差信息。

## 7. 判读规则

1. 如果 w/o `L_Con` 退化，说明原型可分性对预测有效。
2. 如果 w/o `L_Dev` 在 30min/60min 退化更明显，说明偏差一致性对长预测泛化有效。
3. 如果 w/o `L_Con`, w/o `L_Dev` 接近 Full，说明两个自监督约束贡献有限，需要检查收益是否主要来自模型容量或训练调度。
4. 如果 w/o SSDL 明显退化，说明历史锚点和原型偏差注入是框架核心。
5. 如果 w/o SSDL 不退化，下一步应对比普通 AGCRN/动态图 decoder，检查当前轻量实现是否没有充分利用 SSDL 信息。
