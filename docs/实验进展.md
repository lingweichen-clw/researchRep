# 鲁棒交通预测实验进展

更新时间：2026-06-03

## 1. 当前实验目标

当前阶段的目标是以本地复现的 ST-SSDL 为主线，系统拆分自监督偏差学习框架中的关键组件，判断哪些部分对交通预测泛化能力真正有贡献。

本轮实验重点不再讨论第一版中将 DarkFarseer 嵌入 ST-SSDL 的方案，而是回到 ST-SSDL 论文的消融设置：

```text
ST-SSDL full
  - w/o L_Con
  - w/o L_Dev
  - w/o L_Con, w/o L_Dev
  - w/o SSDL
```

对应实验说明与执行命令见：

```text
TrafficRobustST/docs/消融实验方案.md
```

## 4. 实验设置

数据集：METR-LA

输入与预测：

```text
seq_len = 12
horizon = 12
时间粒度 = 5 min
评估步长 = 15 min / 30 min / 60 min
```

原版 ST-SSDL baseline 配置：

```text
rnn_units = 128
rnn_layers = 1
cheb_k = 3
prototype_num = 20
prototype_dim = 64
input_embedding_dim = 3
tod_embed_dim = 20
node_embedding_dim = 25
```

完整模型命令：

```powershell
conda activate research
python -m src.train --model baseline --processed-dir data\METRLA --adj-path data\METRLA_data\adj_mx.pkl --epochs 200 --patience 30 --batch-size 128 --device cuda:0 --seed 999 --rnn-units 128 --prototype-dim 64 --prototype-num 20 --input-embedding-dim 3 --tod-embed-dim 20 --node-embedding-dim 25 --adaptive-embedding-dim 0 --lamb-c 0.01 --lamb-d 1 --lr-scheduler multistep --lr-milestones 50,70 --lr-decay-ratio 0.1 --output-dir log --run-name metrla_stssdl_full
```

## 5. 当前结论

轻量配置在 Overall MAE 上基本追平本地 ST-SSDL 复现结果，并在 RMSE，尤其是 30min 和 60min 上更低：

```text
30min RMSE: 6.1884 -> 6.0668
60min RMSE: 7.3553 -> 7.1714
```

但当前结论还不能说明具体收益来自 ST-SSDL 的哪个部分。下一步需要严格执行论文对应消融实验，分别观察：

1. 原型对比损失 `L_Con` 是否提升原型可分性。
2. 偏差一致性损失 `L_Dev` 是否贡献长预测泛化。
3. 两个自监督损失同时关闭后，模型是否退化为普通原型增强预测器。
4. 整个 SSDL 模块关闭后，历史锚点与原型偏差机制是否仍然必要。
