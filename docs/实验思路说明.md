# 基于 ST-SSDL Baseline 的减法式鲁棒交通预测思路说明

更新时间：2026-06-30

## 1. 当前判断：prototype 坍缩是否影响大

结论：影响很大，但它首先影响的是 ST-SSDL 的“创新模块有效性”和可解释性，不一定立刻让整体 MAE 崩掉。

当前 `metrla_stssdl_full` 可视化结果显示，20 个 learnable prototypes 的有效使用数只有：

```text
effective_proto_num = 2.159811
```

分配最集中的几个 prototype 为：

| prototype | count | 占比 |
|---:|---:|---:|
| P10 | 637515 | 75.19% |
| P17 | 154090 | 18.17% |
| P13 | 31261 | 3.69% |
| P0 | 21780 | 2.57% |

也就是说，P10 与 P17 已经吃掉约 93.36% 的 query 分配。ST-SSDL 论文希望通过 learnable prototypes 把连续 latent space 离散化为多个典型时空模式，再用当前输入 `Xc` 与历史锚点 `Xa` 的 prototype 距离刻画 deviation。如果 prototype 只剩两三个在工作，那么：

1. `low / medium / high deviation` 的可视化不会自然呈现“同一原型 / 邻近原型 / 分离原型”的层次。
2. Figure 5 的 query-prototype PCA 图会变成少数大簇吞并多数样本，而不是多模式离散空间。
3. Figure 6 的 physical prototype pattern 只能恢复少数平均模式，难以支撑“科学信息空间约束起作用”的论证。
4. 预测指标仍可能接近原论文复现值，因为 AGCRN encoder-decoder、time embedding、node embedding 和动态图 decoder 仍在工作；但这说明预测能力可能主要来自主干，而不是 SSDL prototype 约束。

因此，当前可视化异常不是单纯的画图问题，而是暴露了 ST-SSDL baseline 的一个可研究不足：它将“偏差”绑定到离散 prototype 空间，但 prototype 空间存在 lazy mode / assignment collapse 风险。一旦坍缩，模型仍能预测，却无法稳定提供可解释、细粒度、可泛化的 deviation representation。

## 2. 当前工作的切入点

我们不把问题表述为“ST-SSDL 完全错误”，而是表述为：

```text
ST-SSDL 证明了历史锚点与偏差建模的重要性，但其基于 learnable prototypes 的离散偏差空间存在坍缩风险、额外损失依赖和解释不稳定问题。

我们的工作保留“当前输入 vs 历史锚点”的核心思想，删去不稳定的 prototype 离散化与 triplet/deviation auxiliary losses，改为连续、可分解、可校准的轻量偏差建模机制。
```

这符合当前 AI 时代对模型的要求：少堆模块、减少不稳定训练目标、提升可解释性、让简单结构承担更多有效信息。

## 3. 前人论文中用到的思想来源

### 3.1 ST-SSDL：历史锚点与 deviation learning

来源论文：

```text
ST-SSDL-NeurIPS.pdf
```

可借鉴思想：

1. 当前输入 `Xc` 需要与 timestamp-aligned historical anchor `Xa` 对比，而不是只做普通短窗口预测。
2. deviation 是连续强度，不应只用异常/非异常二值标签。
3. deviation-aware representation 应服务于动态图或 decoder，使模型在历史模式失效时仍能预测。

我们保留：

```text
Xc / Xa 双分支输入
deviation-aware forecasting
高偏差样本的可视化与鲁棒性评估
```

我们删除或弱化：

```text
learnable prototypes
Top-2 prototype selection
triplet contrastive loss L_Con
prototype distance consistency loss L_Dev
```

### 3.2 STID：用身份信息替代复杂结构

来源论文：

```text
STID-CIKM.pdf
```

可借鉴思想：

STID 指出复杂 STGNN 的性能收益很多时候来自解决 spatial / temporal indistinguishability。也就是说，模型首先要知道“哪个节点、哪个时间段”，不一定必须依赖复杂图结构或复杂自监督原型。

我们采用：

```text
node identity embedding
time-of-day embedding
day/week periodic identity embedding
```

用于构建轻量的 deviation gate：

```text
g_dev = sigmoid(MLP([deviation_features, node_id_emb, time_id_emb]))
```

这样可以让不同传感器、不同时间段拥有不同的偏差响应强度，同时不引入离散 prototype assignment。

### 3.3 STAEformer：自适应时空嵌入比复杂结构更关键

来源论文：

```text
Adaptive Embedding Makes Vanilla Transformer-CIKM.pdf
```

可借鉴思想：

该论文说明 spatio-temporal adaptive embedding 可以让普通 backbone 获得很强性能，关键不是盲目堆叠复杂结构，而是给模型可学习的时空上下文。

我们采用：

```text
spatio-temporal adaptive embedding as context
```

但不引入 Transformer 主干，只把 adaptive embedding 作为 deviation gate 的上下文输入，保持对 ST-SSDL baseline 的减法式改造。

### 3.4 ST-Norm：用归一化分解高频与局部扰动

来源论文：

```text
ST-Norm-KDD.pdf
```

可借鉴思想：

ST-Norm 将多变量时间序列中的复杂影响拆成 temporal high-frequency component 和 spatial local component，通过 normalization 模块增强常规 backbone。

我们采用：

```text
temporal deviation normalization
spatial deviation normalization
```

即不直接比较 raw `Xc - Xa`，而是先构造两个标准化偏差：

```text
D_t = normalize_over_time(Xc - Xa)
D_s = normalize_over_nodes(Xc - Xa)
```

它们分别表示：

| 偏差 | 张量形状 | 语义 |
|---|---|---|
| `D_t` | `(B,T,N,1)` | 当前窗口相对自身历史锚点的时间高频变化 |
| `D_s` | `(B,T,N,1)` | 某节点相对全路网或局部邻域的空间异常程度 |

### 3.5 STDN / DST-Mamba：趋势-周期分解

来源论文：

```text
STDN-AAAI.pdf
Decomposed spatio-temporal mamba-AAAI.pdf
```

可借鉴思想：

两类工作都强调交通序列可以拆成 trend / seasonal 或 seasonal / trend components。ST-SSDL 的 historical anchor 本质上是周期先验，但它没有显式区分“周期残差”和“趋势漂移”。

我们采用：

```text
trend-season residual decomposition
```

基于已有 `Xc` 和 `Xa`，构造：

```text
R = Xc - Xa
R_trend = moving_average(R)
R_residual = R - R_trend
```

其中：

| 分量 | 语义 | 用途 |
|---|---|---|
| `R_trend` | 当前状态相对历史平均的持续偏移 | 反映拥堵形成、速度整体下降、长期漂移 |
| `R_residual` | 快速扰动与局部噪声 | 反映突发事件、缺失值、局部异常 |

这比 prototype distance 更直接，也更容易解释。

### 3.6 ST-TTC：测试时轻量校准

来源论文：

```text
ST-TTC-NeurIPS.pdf
```

可借鉴思想：

ST-TTC 的核心是不要总在训练阶段堆复杂结构，而是在测试阶段用周期结构偏差做快速校准。它关注 distribution shift、noise、anomaly 下的实时 bias correction。

我们采用一个更轻量的版本：

```text
deviation-aware test-time calibration
```

训练阶段模型输出：

```text
base_prediction
deviation_gate
```

测试阶段根据近期窗口残差维护一个小型 streaming residual memory：

```text
M_t = EMA(M_{t-1}, y_recent - pred_recent)
pred_calibrated = pred + gamma * g_dev * M_t
```

这个模块可以作为可选增强，不改变主干训练，也适合解释“当前输入明显偏离历史锚点时，模型如何校正预测”。

### 3.7 STD-MAE / STEP：长上下文不一定要进主干

来源论文：

```text
Spatial-Temporal-Decoupled Masked Pre-training for Spatiotemporal Forecasting-KDD.pdf
Pre-training Enhanced Spatial-temporal Graph Neural Network-KDD.pdf
```

可借鉴思想：

STD-MAE 与 STEP 都说明短输入窗口容易遇到 spatiotemporal mirage 或长周期上下文不足。它们通常通过预训练补充长上下文。

我们暂不引入预训练大模块，但保留一个轻量接口：

```text
long_context_summary
```

第一阶段不实现预训练，只用 historical anchor / 周期统计作为长上下文代理。后续若你提供对应代码，可以把 STEP/STD-MAE 的 segment-level representation 接入 `deviation_gate`。

## 4. 我们的核心创新方案：DCD-ST

建议工作名称：

```text
DCD-ST: Deviation-Calibrated Decomposition for Robust Spatio-Temporal Forecasting
```

中文名称：

```text
偏差校准分解式鲁棒时空预测
```

一句话概括：

```text
在 ST-SSDL 的当前-历史锚点框架上，删除不稳定的离散 prototype 空间，将偏差建模改为趋势-残差分解、时空身份门控和可选测试时校准，从而以更少辅助目标获得更稳定、可解释的鲁棒预测。
```

## 5. 模型结构设计

### 5.1 保留的 baseline 主干

保留：

```text
AGCRN encoder
AGCRN decoder
node embedding
time-of-day embedding
history anchor input channel
dynamic support for decoder
```

删除：

```text
learnable prototypes: P in (M,D)
prototype projection Wq
query-prototype attention
Top-2 positive/negative prototype
L_Con
L_Dev
```

这样模型从：

```text
Xc, Xa -> Hc, Ha -> Qc, Qa -> prototypes -> Vc, Va -> dynamic graph -> decoder
```

变成：

```text
Xc, Xa
  -> Hc, Ha
  -> deviation decomposition: R_trend, R_residual, D_t, D_s
  -> deviation gate: g_dev
  -> gated hidden fusion: H_de = Hc + g_dev * Phi([Hc-Ha, R_trend, R_residual])
  -> dynamic graph
  -> decoder
  -> optional test-time calibration
```

### 5.2 张量流

输入：

```text
Xc:    (B,T,N,1) 当前窗口
Xa:    (B,T,N,1) 历史锚点
x_cov: (B,T,N,1) time-of-day
y_cov: (B,H,N,1) future time-of-day
```

编码：

```text
Hc = Encoder(embed(Xc, x_cov))  -> (B,N,R)
Ha = Encoder(embed(Xa, x_cov))  -> (B,N,R)
```

偏差分解：

```text
R_raw      = Xc - Xa                         -> (B,T,N,1)
R_trend    = MovingAvg_T(R_raw)              -> (B,T,N,1)
R_residual = R_raw - R_trend                 -> (B,T,N,1)
D_t        = TemporalNorm(R_raw)             -> (B,T,N,1)
D_s        = SpatialNorm(R_raw, adj_matrix)  -> (B,T,N,1)
```

聚合到节点级：

```text
z_dev = Pool_T([R_trend, R_residual, D_t, D_s]) -> (B,N,4)
```

门控：

```text
z_id = concat(node_embedding, time_embedding_last) -> (B,N,E)
g_dev = sigmoid(MLP([z_dev, z_id, Hc-Ha]))          -> (B,N,R)
```

融合：

```text
Delta_H = MLP([Hc-Ha, z_dev])       -> (B,N,R)
H_de    = Hc + g_dev * Delta_H      -> (B,N,R)
```

动态图：

```text
node_embeddings = HyperNet([H_de, Ha, g_dev])
support = softmax(relu(node_embeddings @ node_embeddings^T))
```

解码：

```text
prediction = AGCRNDecoder(H_de, support, y_cov) -> (B,H,N,1)
```

### 5.3 损失函数

主训练损失从 ST-SSDL 的：

```text
L = L_MAE + lambda_con * L_Con + lambda_dev * L_Dev
```

简化为：

```text
L = L_MAE + lambda_smooth * L_gate_smooth + lambda_sparse * L_gate_sparse
```

其中辅助损失只约束 gate，不再训练离散 prototype：

```text
L_gate_smooth = mean(|g_dev[t] - g_dev[t-1]|)
L_gate_sparse = mean(g_dev)
```

设计含义：

1. `L_MAE` 保证预测性能。
2. `L_gate_smooth` 防止门控在时间上剧烈抖动。
3. `L_gate_sparse` 鼓励模型只在必要时启用偏差校正，符合“做减法”思想。

第一版实现甚至可以只用：

```text
L = L_MAE
```

把 gate 作为监督外的可学习中间变量，通过预测误差自然学习。

## 6. 我们相对 ST-SSDL 的明确创新点

### 创新点 1：从离散 prototype deviation 改为连续 decomposition deviation

ST-SSDL 的不足：

```text
prototype assignment 容易坍缩；
偏差解释依赖 Top-1/Top-2 prototype；
可视化结果对 prototype 使用均衡性高度敏感。
```

我们的改进：

```text
用 R_trend / R_residual / D_t / D_s 直接表示偏差；
不再需要 prototype_num、prototype_dim、Top-K assignment；
偏差可解释性来自物理空间残差分解，而不是不稳定的 latent cluster。
```

可视化对应：

```text
画 trend deviation curve
画 residual anomaly heatmap
画 spatial deviation map
画 g_dev 随 high/medium/low deviation 的变化
```

### 创新点 2：时空身份条件化的轻量偏差门控

ST-SSDL 的不足：

```text
同一组 prototypes 面向所有节点和时间段，容易让高频大类模式吞掉细粒度模式。
```

我们的改进：

```text
借鉴 STID / STAEformer，把 node identity 与 time identity 注入 gate；
不同节点、不同时间段拥有不同偏差响应；
不新增复杂 backbone，只新增小 MLP。
```

### 创新点 3：训练时做减法，测试时可校准

ST-SSDL 的不足：

```text
鲁棒性完全依赖训练阶段学到的 prototype 空间；
测试分布漂移或突发异常下，prototype 若已坍缩就无法可靠调整。
```

我们的改进：

```text
借鉴 ST-TTC，增加可选 deviation-aware residual calibration；
只在测试阶段维护轻量 residual memory；
当 g_dev 高时校准更强，当 g_dev 低时保持原预测。
```

### 创新点 4：可解释性从 latent PCA 转向物理偏差诊断

ST-SSDL 的可视化依赖：

```text
prototype PCA
prototype assignment
query-prototype distance
```

我们的可视化依赖：

```text
current vs anchor residual
trend/residual decomposition
spatial normalized deviation
gate activation
calibration correction
```

这更容易和交通场景解释对应：拥堵形成、速度恢复、局部传感器异常、全局高峰周期漂移。

## 8. 实验设计

### 8.1 主对照

| 实验名 | 目的 |
|---|---|
| ST-SSDL full | 原论文 baseline |
| ST-SSDL w/o SSDL | 判断 AGCRN 主干本身强度 |
| DCD-ST w/o calibration | 验证连续偏差分解与门控是否优于 prototype |
| DCD-ST full | 验证测试时校准在高偏差/缺失场景下是否提升鲁棒性 |

### 8.2 消融实验

| 消融 | 去掉内容 | 验证问题 |
|---|---|---|
| w/o trend | 去掉 `R_trend` | 持续偏移是否重要 |
| w/o residual | 去掉 `R_residual` | 突发扰动是否重要 |
| w/o ST identity | 去掉 node/time embedding from gate | STID 思想是否贡献细粒度响应 |
| w/o spatial norm | 去掉 `D_s` | 空间局部异常是否重要 |
| w/o temporal norm | 去掉 `D_t` | 时间高频偏差是否重要 |
| w/o calibration | 去掉测试时 residual memory | 测试阶段校准是否改善 distribution shift |

### 8.3 可视化实验

替代 ST-SSDL Figure 4-6 的可视化：

1. Low / medium / high deviation 下，画 `Xc`、`Xa`、prediction、ground truth。
2. 同一图中补充 `R_trend` 与 `R_residual`。
3. 画 `g_dev` 的节点热力图，观察高偏差样本是否激活更强。
4. 缺失值实验中画 calibration 前后预测对比。
5. 按 gate activation 统计 MAE，验证 gate 高的样本是否确实更难、校准收益更大。

### 8.4 判定标准

如果 DCD-ST 成立，应观察到：

1. Overall MAE/RMSE 至少不弱于 ST-SSDL full。
2. High deviation 组 MAE/RMSE 优于 ST-SSDL full 或 w/o SSDL。
3. 缺失值场景中 full calibration 优于 w/o calibration。
4. 可视化中 `g_dev` 与 `|Xc-Xa|`、预测误差或校准幅度呈正相关。
5. 模型不再需要 prototype usage entropy 作为健康指标，因为没有离散原型坍缩风险。

## 9. 预计贡献表述

论文式贡献可以写成：

1. We identify a prototype assignment collapse problem in ST-SSDL-style self-supervised deviation learning, where the forecasting backbone remains competitive but the discrete scientific information space loses interpretability and fine-grained deviation modeling ability.
2. We propose a subtraction-oriented deviation modeling framework that removes learnable prototypes and auxiliary contrastive/deviation losses, replacing them with continuous trend-residual decomposition and spatio-temporal identity-conditioned deviation gating.
3. We introduce a lightweight test-time residual calibration mechanism guided by deviation gates, improving robustness under high-deviation and missing-value scenarios without retraining or adding a heavy backbone.
4. We design physical-space diagnostic visualizations for deviation decomposition, gate activation, and calibration correction, making the model behavior easier to interpret than latent prototype PCA.

## 10. 第一阶段实现优先级

第一阶段先实现：

```text
DCD-ST without test-time calibration
```

只做三件事：

1. 删除 prototype 相关路径。
2. 加入 `DeviationDecomposition` 与 `DeviationGate`。
3. 复用 AGCRN encoder-decoder 和现有 train/evaluate 逻辑。

第二阶段再实现：

```text
test-time calibration
visualize_dcd.py
```

这样风险最低，也最符合“在 baseline 上做减法”的要求。
