# DHA-DCD-ST 第一版实现与实验计划

更新时间：2026-07-01

## 1. 当前实现目标

本版实现的是 **DHA-DCD-ST v1：单分布统计锚点消融版**。

核心目的不是马上引入复杂的多锚点 selector，而是先回答一个更基础的问题：

```text
ST-SSDL / DCD-ST 中的 historical mean anchor 是否过于粗糙？
如果把第三通道历史锚点从 mean 替换为 median / q25 / q75 / recent，
同一个 DCD-ST 下游结构是否能得到更好的预测与偏差表征？
```

因此本版严格保持原有数据张量契约：

```text
x: (B,T,N,3)
y: (B,H,N,3)

channel 0: traffic value
channel 1: time_in_day
channel 2: history_anchor
```

变化只发生在 `channel 2` 的生成方式。

## 3. 历史锚点定义

对每个时间戳 `t` 和节点 `n`，先计算：

```text
slot_id(t) = weekday(t) * slots_per_day + slot_in_day(t)
```

METR-LA 默认 5 分钟粒度：

```text
slots_per_day = 288
slot_id in [0, 2015]
```

锚点表只由训练段原始时间序列构造：

```text
train_end = int(num_steps * train_ratio)
```

对于同一个 `weekday-slot` 和同一个节点，从训练段取所有非零历史值：

```text
V_slot,n = { X_tau,n | tau < train_end, slot_id(tau)=slot_id(t), X_tau,n != 0 }
```

五种锚点：

```text
mean:   average(V_slot,n)
median: percentile_50(V_slot,n)
q25:    percentile_25(V_slot,n)
q75:    percentile_75(V_slot,n)
recent: 训练段内最后一次同 weekday-slot 的非零值
```

如果某个节点在某个 slot 没有有效历史值，则回退到该节点训练段非零均值。这个回退只用训练段，避免验证集和测试集泄漏。

## 4. 张量流审查

### 4.1 预处理输出

`DHA-DCD-ST/preprocessing.py` 读取：

```text
data/METRLA_data/METR-LA.h5
```

得到：

```text
values         : (L,N)
time_in_day    : (L,N)
history_anchor : (L,N)
data           : (L,N,3)
```

滑窗后：

```text
x: (B,12,N,3)
y: (B,12,N,3)
```

并保存：

```text
trainhis.npz
valhis.npz
testhis.npz
metadata.json
```

### 4.2 训练入口拆分

`src/data.py::prepare_x_y()`：

```text
x0    = x[..., 0:1] -> (B,T,N,1)
x_cov = x[..., 1:2] -> (B,T,N,1)
x_his = x[..., 2:3] -> (B,T,N,1)
y0    = y[..., 0:1] -> (B,H,N,1)
y_cov = y[..., 1:2] -> (B,H,N,1)
```

`src/data.py::normalize_splits()` 会归一化：

```text
x[...,0] value
x[...,2] history_anchor
```

不会归一化 `time_in_day`。

### 4.3 模型内部

`--model dha` 加载：

```text
DHA-DCD-ST/dha_dcd_st.py::DHADCDST
```

当前 `DHADCDST` 继承 DCD-ST 主体：

```text
Xc = x0
Xa = x_his

Hc = Encoder(Xc, x_cov) -> (B,N,R)
Ha = Encoder(Xa, x_cov) -> (B,N,R)
R  = Xc - Xa

z_dev, R_trend, R_residual, D_t, D_s = DeviationFeatureExtractor(R)
g_dev, Delta_H = DeviationGate(Hc, Ha, z_dev, node_id, time_id)
H_de = Hc + g_dev * Delta_H
prediction = Decoder(H_de, y_cov) -> (B,H,N,1)
```

因此第一版实验的可归因性很强：

```text
同一个模型、同一套训练超参，只替换历史锚点统计量。
```

## 10. 实验安排

### 10.1 第一轮：单锚点统计量消融

| 实验 | processed_dir | 目的 |
|---|---|---|
| DHA-mean | `data/METRLA_anchor_mean` | 对齐原 historical average anchor |
| DHA-median | `data/METRLA_anchor_median` | 验证稳健中心趋势 |
| DHA-q25 | `data/METRLA_anchor_q25` | 验证低流量/畅通模式 |
| DHA-q75 | `data/METRLA_anchor_q75` | 验证高流量/拥堵模式 |
| DHA-recent | `data/METRLA_anchor_recent` | 验证近期同槽历史 |

判定标准：

```text
如果 median / q25 / q75 / recent 任意一个稳定优于 mean，
说明历史均值锚点确实存在信息压缩问题。
```

### 10.2 第二轮：固定门控对照

每个最好锚点都应补一个固定门控版本：

```powershell
python -m src.train --model dha --processed-dir data\METRLA_anchor_median --adj-path data\METRLA_data\adj_mx.pkl --run-name metrla_dha_anchor_median_fixed_gate_05 --epochs 100 --patience 20 --batch-size 64 --lr 0.001 --lr-scheduler multistep --lr-milestones 40,70 --lr-decay-ratio 0.1 --seed 999 --fixed-gate 0.5
```

判定：

```text
如果非均值锚点提升明显，但 learned gate 与 fixed gate 仍接近，
说明下一步应重构 gate / reliability，而不是否定 DHA 锚点。
```

### 10.3 第三轮：高偏差样本诊断

需要统计：

```text
|Xc - Xa| 分位数
high-deviation split 的 MAE/RMSE/MAPE
gate_mean / gate_std / gate_q10 / gate_q90
Delta_H norm
Hc-Ha norm
```

重点看：

```text
非均值锚点是否降低 high-deviation 区间误差；
gate 是否仍卡在 0.5 附近；
不同锚点下 residual 分布是否更健康。
```

## 11. 下一阶段扩展

如果第一轮发现非均值锚点有效，再进入第二版 DHA：

```text
x[...,2] anchor_mean
x[...,3] anchor_median
x[...,4] anchor_q25
x[...,5] anchor_q75
x[...,6] anchor_recent
```

新增：

```text
prepare_x_y_dha()
AnchorSelector
AnchorReliability
need * reliability gate
```

此时模型不再只是替换单锚点，而是学习：

```text
当前窗口更应该参考哪一种历史模式；
历史分布是否可靠；
高偏差时应该使用 anchor correction 还是 self correction。
```

## 12. 当前结论边界

本版代码能回答：

```text
均值锚点是否过弱；
非均值统计锚点是否能改善 DCD-ST；
历史锚点问题和 gate 问题是否可以拆开分析。
```

本版代码还不能回答：

```text
多锚点 soft selector 是否有效；
reliability 是否能抑制 spatiotemporal mirage；
真实历史 top-k retrieval 是否优于统计锚点。
```

所以实验汇报时不要把本版称为完整 DHA selector 模型，应称为：

```text
DHA-DCD-ST v1: distributional single-anchor ablation
```
